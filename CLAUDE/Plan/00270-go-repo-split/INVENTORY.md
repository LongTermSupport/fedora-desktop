# Plan 00270 inventory: every Go package and where it goes

Built from `go list -mod=vendor -f '{{.ImportPath}}|{{join .Imports ","}}' ./...` in `src-go/`
(255 packages) and the same in `src-go/qa/` (105 packages), folded to one row per top-level
unit (`internal/<x>` with its subpackages, or `cmd/<x>`). "Deps" are the in-module units it
imports. "Users" are the units that import it (`c:` a command, `i:` an internal package).
"External" lists the third-party modules it imports directly. The last column is the coupling
to fedora-desktop that has to be cut or inverted before the unit can leave.

The groups are candidates (PLAN.md, "The proposed repos"):

- **kit**: shared leaf library: process, terminal, prompts, files, git.
- **teamchat**: the v2 agent-team bus (proto, member, admin, host).
- **ccy**: the launcher, its sessions, conversation record, teams and the container tools.
- **stays**: desktop tools that belong to this host build. They stay in fedora-desktop and
  import kit (and, for a few, ccy) as a pinned module.
- **stays-v1**: the v1 bus. It stays in fedora-desktop, because the new repositories carry v2
  only, absolutely clean (PLAN.md Q4). No moving package may import it (PLAN.md Task 1.5).
  Its removal from fedora-desktop is gated and not approved (PLAN.md Phase 7).

Regenerate the graph with the two `go list` commands above. Take the import lists as the
source of truth and this table as a reading of them on the day it was written.

## Cross-boundary edges that block a clean cut

Each of these is an import that runs the wrong way, or a package that mixes two groups. Each
one is a task in PLAN.md Phase 1.

| Edge or mix                                                                                                                                                                                           | Why it blocks                                                         | Cut                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stdinread` → `teamchat/clock`, `leakcheck` → `teamchat/clock`                                                                                                                                        | a kit leaf imports teamchat, so kit cannot be extracted first         | the clock seam moves to kit (`kit/clock`) and teamchat imports it                                                                                                    |
| `systemd` holds the agent-bus homeserver units and the Element scope                                                                                                                                  | a kit leaf carries teamchat and desktop names                         | generic `systemctl`/`systemd-run` wrapper to kit; homeserver units to teamchat/host; Element scope to the desktop tools that use it                                  |
| `sudo` names root paths (`sudo.AgentBus`, `sudo.InstallTool`)                                                                                                                                         | the sudo wrapper is generic, the paths are not                        | wrapper to kit; the path constants to their owners (ccy, the v1 bus)                                                                                                 |
| `teams` runs `playbooks/imports/play-agent-bus.yml` from the checkout (`main.RootDir`)                                                                                                                | ccy-teams cannot run without a fedora-desktop checkout                | a provisioner hook: ccy-teams runs a configured command for "install this seat"; fedora-desktop's play sets it to its play                                           |
| `ccproject` (`cc-project-dir`) needs `main.RootDir`                                                                                                                                                   | same                                                                  | same hook, or the checkout path from ccy's own config                                                                                                                |
| `declare`, `bus` read `host_vars` through `declare.py` (Python)                                                                                                                                       | ccy calls into a Python helper of this repository                     | both are `stays-v1` and stay here (Q4); ccy reads declarations only through teamchat's `declare/hostvars` (Go, the v2 declarations)                                  |
| `playlock` takes the lock of `helpers/play_lock/lock.py`                                                                                                                                              | the lock is Ansible's; a standalone ccy has no plays                  | keep the file protocol, documented as ccy's; fedora-desktop's Python lock and ccy's Go lock stay one protocol, held by a parity test in fedora-desktop               |
| `matrixclients` reads `helpers/pingbus/matrix_clients.json`                                                                                                                                           | a data file of this repository                                        | the list moves into ccy as embedded data; fedora-desktop's Python reads it from the installed ccy release                                                            |
| `compactfloor` mirrors `play-claude-yolo.yml`'s `ccy_restore_compact_floor`                                                                                                                           | a value owned by a play                                               | ccy owns the default; the play passes an override only                                                                                                               |
| `ccylimits` parity test against `files/var/local/claude-yolo/lib/container-limits.bash`                                                                                                               | none once both move together                                          | moves with ccy (the bash library travels in the same extraction)                                                                                                     |
| `teamchat/installplay` tests `play-teamchat.yml`                                                                                                                                                      | a test of a play                                                      | stays in fedora-desktop as a test of the play against the pinned teamchat release                                                                                    |
| `teamchat/declare/hostvars` reads an Ansible `host_vars` file                                                                                                                                         | the format is plain YAML with `!vault` tags, but it is Ansible's file | keep the reader (it is the declaration format); name it "the declarations file" and test it on fixtures, not on this repo's tree                                     |
| `teams/*` imports 16 teamchat packages under `internal/` (17 counting tests)                                                                                                                          | Go forbids importing another module's `internal/` packages            | teamchat publishes them as API: the list below                                                                                                                       |
| `hostcheckout` knows the host's LXC rootfs path                                                                                                                                                       | an install-side path                                                  | a ccy config value, set by the play                                                                                                                                  |
| test files reading checkout paths (`teamchat` 2, `teams` 4, `ccylaunch` 3, `registry` 2, `restore` 1, `screen` 1, `transcript` 1, `sessions` 1, `declare` 1, `bus` 2, `pingbus` 1, `matrixclients` 1) | a test that reads `../../..` of this repository fails in another      | each is moved to `testdata/` in its package, or becomes a fedora-desktop test of the integration; the `stays-v1` ones (`declare`, `bus`, `pingbus`) stay as they are |

### The teamchat packages ccy imports (become teamchat's public API)

`proto`, `paths`, `seat`, `status`, `state`, `matrix`, `declare`, `declare/hostvars`, `sweep`,
`duty`, `member/state`, `member/cli`, `member/client`, `member/placeissued`, `host/lxc/lxcstate`,
`host/lxc/guestfacts`, and `clock` (which moves to kit). Everything else under `teamchat`
stays `internal/`.

## src-go/qa (module `github.com/LongTermSupport/fedora-desktop/src-go/qa`)
