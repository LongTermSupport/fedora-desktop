# Backlog: what a coordinator's retrospective asks of v2

A team coordinator's own retrospective of 2026-11-23 found patterns that cost the owner time.
The items below fall to v2 (teamchat, ccy, ccy-teams). They are v2 only: v1 gets nothing.
None of this is scheduled yet; each item becomes a task, test first, when it is picked up.
Task 4.7 in [PLAN.md](PLAN.md) tracks this list.

**R0, the prerequisite: v2 has no questions verbs yet** (PLAN.md, Task 6.4 step 5). The
questions room syncs, but a seat cannot ask a human, answer in a thread, close or list a question
on v2. R1-R4, R10 and R11 build on those verbs, and a coordinator cannot move to v2 without them,
since asking the owner is its job. So R0 comes first: `ask-human`, `thread Q<n>`, `close`,
`retitle` and a list of open questions, as Plan 00211's SPEC describes for v1, ported test first.
