## What was built

**inbox** (imports `clock`, `proto`, `x/sys/unix`, std). Each delivery is one connection, and
each of its four phases is bounded by `clk.AfterFunc(PhaseTimeout, close)`:

1. Connect.
2. The auth line.
3. The user line.
4. Finish: half-close, then read to EOF.

Connect opens the path `O_PATH|O_NOFOLLOW`, `fstat`s it, and refuses anything that is not a
socket, or a socket another uid owns. It then connects through `/proc/self/fd/<n>`.

- `ENOENT`, `ECONNREFUSED`, `ENOTSOCK`, a symlink and a foreign-owned socket are `ErrGone`.
- Any other connect or auth failure is `ErrRetry`. So is the phase running out, or the caller's
  context ending.

`WriteUser` has three outcomes: nil for a full write, `ErrPartial` when part of the line was
written, and `ErrRetry` when nothing was. `Finish`'s error never undoes a full write. Every error
wraps both the sentinel and its cause.

**fakeinbox** (imports `clock`, std).

- It speaks strict auth and user lines. A non-JSON line, unknown fields, trailing data,
  non-ASCII, a wrong type or role, a cut line, or a line after the user line is `framing`.
- A wrong token is `auth`, and the connection is closed.
- It applies the duplicate filter, then the bucket, on `clk.Boot()`. A duplicate does not use a
  token, and the window runs from the last accepted copy.
- It has `Hold`, `Refuse` (closes the listener and keeps the path), `Remove` and `Close` (which
  ends held connections and unlinks the path).
- `OnAccepted` is called before the connection closes, so a caller's `Finish` returns after the
  frame was handed on.
- It never records a token: an auth frame's `Content` is always empty.

**deliver** (imports `proto`, `state`, `paths`, std; pure).

- `Choose` skips handed and held items.
- `Build` maps each item from its verdict and the caller's `Namer`:
  - HUMAN: body, `re` from `ReplyTo`, `revises`.
  - PEER: text, else body; `re`; `copy`.
  - PING: verb, ref, branch; `trust` from `Forge`; `re` from `Answer.Ping` or the reply; `copy`.
  - NOTICE: event, subject, and the reason (left) or role (added, role); or the carried account.
  - TIMEOUT: the event id from the key, `silent`, the verb and ref.
  - A questions-room entry carries `Questions`.
- `Build` then checks each entry's `Lines()`, sorts by A 13.7 (stable; TIMEOUTs keep the
  caller's order), draws the nonce, and calls `Fit` then `Render`.

## Exported API as built

```go
package fakeinbox
type Options struct{ Token string; Clock clock.Clock; DupWindow time.Duration; Bucket int; PerSecond float64 } // zero = 30 s, 30, 0.5

func (b *Inbox) Path() string

func (b *Inbox) Await(ctx context.Context, n int) error // added: wait for n frames without sleeping

package deliver
type Item struct{ Pending state.Pending; Verdict *proto.Verdict; Timeout *Timeout; Question *proto.EntryQuestion }

```

## Decisions

1. **Additions to section 3's API.** These are additions only; nothing named there changed.
   - `Item.Question`: the question index is not in deliver's inputs. n3e-6 fills it from
     `proto.QuestionIndex`; nil renders `question: none`.
   - `fakeinbox.Await`: so tests wait on frames, not time.
   - `Hold` returns `func()`, because the linter refuses a named result.
2. **The timeout tests do not use the fake.** A unix socket buffers far more than an envelope,
   so a held fake can never make a write block. The tests for a phase running out (connect, the
   auth line, before the user line, inside it) drive the conn over `net.Pipe`, which has no
   buffer, through an unexported `connect` seam. The `Finish` timeout and the wrong token
   (`ErrRetry`) do run against the real fakeinbox.
3. **An invalid target is a plain error.** A relative socket or an empty token is neither
   `ErrGone` nor `ErrRetry`: it is the caller's bug.
4. **A restored item with no verdict is left pending.** It goes in `Built.Left` and counts in the
   pending line. It is never rendered, and it is not an error.
5. **Unrenderable items are dropped.** An unknown item kind, or a TIMEOUT with no `Timeout`, is
   `Failed` (`render`).
6. **Nothing to send means nothing drawn.** With no entry and no trailing fact, `Text` is empty
   and no nonce is drawn. Left items alone do not make a delivery.
7. **`Namer` returns `role == ""` for a human.** The `copy:` line is the humans in the item's
   `to`. `from:` takes a handle, not the short name: A 13.2's `<sender>` refuses a short name,
   unlike the engine's record namer.
8. **Errors from `Build`.** A nonce that cannot be drawn, or facts that fail their slot, are
   errors.
