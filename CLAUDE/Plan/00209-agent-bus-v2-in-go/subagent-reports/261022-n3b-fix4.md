## 1. R2-1 (major): the error is classed by where it came from, not by its errno

**Change.** `guestroot.ErrGuest` is new. `guestFault` (`guestroot/bound.go`) classes the error
of every call at `bounded`, which every read and write below the root passes through. An error
is wrapped in `ErrGuest`, with the errno kept, unless it is one of these:

- already classed: `ErrRefused`, `ErrTooLarge`, `fs.ErrNotExist` (a fact, not a fault), or the
  root being closed;
- EMFILE, ENFILE or ENOMEM: the host's resources;
- a `*net.OpError` from the systemd connect: the guest's bus being down, which callers route
  as unit-down or offline, so it is left as it was.

The other host faults the lead named fall outside `bounded` and stay unclassed:

- an error before the pin (`Pin`);
- the host's own /proc: the pidfd poll in `Alive`, and `InitExe`.

`ErrStalled` now wraps `ErrGuest`, not `ErrRefused`. In lxc, `refused()` is `badFact || ErrGuest`, and that routes the error to the member. `badFact` is the old TB1 or grammar
refusal.

**Tests.**

- `guestroot TestAnErrnoBelowTheRootIsTheGuests` fails each sys call in turn (openat2, openat,
  fstat, read, getdents, flock, close, write, fchmod, fsync, renameat2, mkdirat) under Stat,
  ReadFile, ReadDir, ProbeLock, WriteFile and MkdirAll:
  - EACCES, EIO and ENXIO come back as `ErrGuest`, with the errno kept and no TB1 refusal;
  - EMFILE, ENFILE and ENOMEM do not become `ErrGuest`.
- `TestAMissingPathIsNotAGuestFault`.
- `TestAConnectNoOneAnswersIsNotAGuestFault`: ECONNREFUSED is not an `ErrGuest`.
- lxc `TestKitSweepListingFaultKeepsEveryDigest`: EACCES and EIO on another user's
  `/run/user/<uid>` run root keep the old digest, no seat fails, and the seat joins. It was red
  before the fix: every seat failed at `kit`.
- lxc `TestCheckoutReadFaultFailsThatSeatAlone`: EACCES and EIO on one checkout's
  `.git/config` refuse that seat (Drift, step reads). A seat of the same container on another
  checkout joins. It was red before the fix: every seat of the container failed as a host
  fault.
- lxc `TestLockProbeErrnoIsNotFree`: EACCES and EIO on the lock fail the L3 wait (there is no
  `guest remove`) and fail the health probe. It was green before the fix. It guards against
  the naive version of the fix, which would put `ErrGuest` into the free test.

## 2. R2-2 (minor): a stall read as free

**Change.** `lockFree(err)` (`apply.go`) is now the one test for a free seat at both sites,
`waitFree` and `seatLockOf`. It is true for a TB1 refusal and for a lock that is not there.
A guest's error or a stall fails the probe. In the first commit this was an explicit
`ErrStalled` exclusion. Once R2-1 took `ErrStalled` out of `ErrRefused`, the exclusion
followed from the classes and was dropped.

**Tests.**

- `TestAbsentWaitProbeFailures` now also runs a stall: the leave fails at `wait` and there is
  no `guest remove`.
- `TestProbeHostFaultsAreErrors` has two new rows, a stalled read and a stalled lock probe, and
  both are errors.
- All three were red before the fix: the stalls read as free.

## 3. R2-3 (minor): a stall was paid again by every call that crossed it

**Change.**

- `guestroot.Memo` holds the first stall of one scope.
- `Root.Scoped(m)` is a view of the same pinned root. `Root` now embeds a shared `*pinned`
  core, which holds the descriptors, the calls in flight and the late errors.
- A scoped call checks the memo after `Alive`, so a container that died still answers
  `ErrGone`. Once a stall is recorded, the call answers `ErrStalled` at once, names the first
  stall, and makes no system call. This holds for reads, writes and the dial.
- `lxc.Root` gains `Scoped`. `lxc.Pinned` adapts a `*guestroot.Root` and the wire uses it, and
  the admin test fake uses it too.
- `guestBox.rootOf(m)` gives one memo per guest user per container per run. It covers the
  checkout reads, the service facts, the v1 holdback, the unit read and write, the systemd
  dial and the L3 wait.

**Scope decision.** The lead asked for the memo to be scoped per member, per run. I keyed it by
container and guest user, which matches `--member C/U` in the owner rule:

- A stall comes from a guest user's own mount, so it is that user's.
- In this code a failed seat is `done` and makes no more calls in its phase, so a per-seat
  memo would change almost nothing.
- Keyed by user, the review's scenario costs one bound: two seats on one stalled checkout.

The calls that span the whole container are left unscoped: passwd, the kit placement and the
kit sweep. A stall there is not one member's.

**Tests.**

- `guestroot TestAStallIsPaidOncePerMemo`: after one stall, ReadFile, Stat, ReadDir,
  ProbeLock, Dial and WriteFile through the same memo answer `ErrStalled` naming `/stalled`,
  and make zero system calls. Another memo and the unscoped root still read. It was red with a
  stub that had no effect: 41 system calls were made.
- lxc `TestAStallIsWaitedOutOncePerUser`: agent1's seats 1 and 2 are on a stalled checkout.
  The bound is waited out once (it was twice before the fix), neither seat joins, and agent2's
  seat on another checkout joins. The fake `stallLog` honours a memo the way guestroot does.
  guestroot's own memo is proven by the test above, so this test proves the lxc wiring.
- `TestPinnedScopedReadsTheSameRoot` covers the adapter.

## 4. N1 (nit): a stalled tmux stat said tmux was not installed

**Change.** Nothing in `tmux()` changed. With R2-1, a stall or an errno is no longer an
`ErrRefused`, so `tmux()` returns the error unchanged. It is still routed as the member's
failure. Only a tmux that is missing, is a link, or is not a regular file still sends the
operator to the container's play.

**Test.** `TestTmuxFaultKeepsItsCause` runs a stall and an EIO. Each keeps its cause, is
`refused()`, and does not say "installs it". With the old classes the stall would have taken
the "installs it" branch. I did not run that red state, because a stash or checkout is not
allowed. The test is in the R2-1 commit.
