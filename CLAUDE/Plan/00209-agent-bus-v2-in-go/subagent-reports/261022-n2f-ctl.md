# n2f part "ctl": the child's own files and the Opener (SPEC-n2f OP1-OP6)

Branch `feat/bus-v2-n2f-ctl`, package `src-go/internal/teamchat/ctl` (`ctl.go`, `ctl_test.go`,
`tuwunel_test.go`). fakehs needed no change.

## What was built

- `ctl.Config{Root, Now, Rand, Admin}`, `ctl.Open(ctx, cfg, team, port, regKey) (admin.Opened, error)`
  and `(Config).Opener() admin.Opener`, with the names the brief gave. Defaults: `time.Now`,
  `crypto/rand.Reader`, and `matrix.NewAdmin` on `http://127.0.0.1:<port>`.
- `Opened`: the admin client with the token; `RosterPath`, `RoomsPath` and `GuestDir` under
  `Root + paths.CtlState(team)`; `Now`; and `Member`, which is `matrix.NewMember` on the same
  base with `PlainHTTPHosts ["127.0.0.1"]`.
- `ctl/<team>/` is opened `O_DIRECTORY|O_NOFOLLOW`. It must be owned by the euid with mode
  0700\. Every file is reached from that fd: reads use `openat` with
  `O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC`, then `fstat` (must be regular) and a size cap. Writes
  follow OP4: an exclusive 0600 temporary file, fsync, `linkat` (which fails with EEXIST if the
  name exists), unlink the temporary, fsync the directory.
- Bootstrap step 1 (OP3) uses the `TCADMIN` device.
- Tests for OP5. Every `Open` error in every test is checked when the test ends: it must not
  contain the registration key, any token or password file content the test saw, or a seeded
  password.
- Crash tests, each finished by the next `Open`:
  - before register (the request is dropped);
  - after register, before the token (the answer is dropped after the server acts);
  - after login, before the token;
  - after the token, before the password is deleted.
- Refusal tests:
  - a token that belongs to another user;
  - a token the server refuses;
  - "user in use" with no password file (names restore);
  - a password the account does not take;
  - a login that answers as another account.

## Decisions

| ID     | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| n2f-C1 | A refusal is `*apply.Error{Op: OpTeamApply, Step: "admin", Drift: true}`, which `admin.ExitCodeOf` maps to 70. The tests check this through `ExitCodeOf`. A bad directory, a bad file, or a missing token is a plain error (78 in Serve). A homeserver failure keeps its matrix kind (69 through `ExitCodeOf`). **For the admin part:** `Serve` turns every Opener error into `ClassConfig`, so 70 and 69 come out as 78. It should use `errorClass` first and fall back to `ClassConfig`. |
| n2f-C2 | When a password file is present, Open registers with it first. If the answer is `M_USER_IN_USE`, the account was ours from an earlier run, so it logs in. The design's "log in with it" fails after a crash that came before register. Register-first covers both crash points.                                                                                                                                                                                                            |
| n2f-C3 | If a fresh password meets `M_USER_IN_USE`, that password is deleted and the bootstrap is refused, naming restore. A login refused with an existing password is also refused naming restore.                                                                                                                                                                                                                                                                                                |
| n2f-C4 | Register's own session token is thrown away. It is not stored and not logged out. The stored token comes from the `TCADMIN` login, so each fresh bootstrap leaves one extra admin device.                                                                                                                                                                                                                                                                                                  |
| n2f-C5 | With a key and a token: a whoami answered 401 is refused (70, naming restore). A whoami with no answer is unreachable (69). After whoami confirms the token, a leftover password is deleted (crash case 4). Without a key, Open makes no server call and leaves a leftover password in place.                                                                                                                                                                                              |
| n2f-C6 | The admin ID is `@admin:` plus `paths.ServerName(team)`, because the child reads no file of root's.                                                                                                                                                                                                                                                                                                                                                                                        |
| n2f-C7 | If `ctl/<team>/` is absent, Open refuses and does not create it. Root's host step creates it (SPEC-n2d).                                                                                                                                                                                                                                                                                                                                                                                   |
| n2f-C8 | `Deps.Approvals` is left nil, because `Serve` sets it for `team.apply`.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| n2f-C9 | The token file must hold the token bytes exactly: no newline, 1 to 4096 bytes in 0x21-0x7e. The password file must be exactly 64 lowercase hex digits. Temporary names are drawn from `Config.Rand`. A temporary file left by a crash stays where it is; its random name is never reused.                                                                                                                                                                                                  |
