# Fact check: PrivatePIDs removal and the resolver directory (DESIGN-v2-C-host.md, SPEC-n2g.md)

Diff: `.claude/hooks-daemon/untracked/plan-fact-check/00209-agent-bus-v2-in-go.diff`. The sources are the
working-tree files.

## REFUTED

None outright. Two claims are only partly supported, so they are listed first.

1. **Claim 11 (backup "signals only an active, ready homeserver") is only partly true.**
   - What the code does: `backup/take.go` `take()` calls `ready()` (line 177), which needs
     `ActiveState == active`, an `InvocationID`, and `ServerVersion` answering on the port.
     `sameInvocation()` (line 192) then checks the unit is still active in that same invocation, and
     only then does `Units.Kill(unit, "main", SIGUSR2)` run (line 116).
   - "Ready" means the Matrix API answers. That is a proxy for "Tuwunel has installed its SIGUSR2
     handler". The code does not establish it, and nothing in the repository says the API answers only
     after the handlers are installed.
   - Effect on the plan: the sentence is right about what the code checks. "a signal sent before Tuwunel
     installs its handler kills it" is a spike claim (see claim 7), and BT1 only makes that window unlikely.
     If the plan wants more, it should say "answers on its port" rather than imply a handler check.
2. **Claim 9 (the 226/NAMESPACE EACCES, "systemd 259" and "the first real run") is supported only by
   repository text.** The sources are `CLAUDE/QA.md:2604-2605` and `261111-resolver-bind-report.md:30`.
   No fixture or log can be checked from here. Treat it as UNVERIFIABLE-HERE for the live fact.
