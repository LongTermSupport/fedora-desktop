The open is about 4.9 times faster. `--list` came out about 20 ms slower in both script runs,
so I looked into it. In this world both revisions start exactly one Python for the teams
(F44 `declare overview`, HEAD `declare status`, each 100-125 ms run alone). F44's seat list here
is the suite's bash stub, not Python, so it costs F44 little. HEAD's extra in-process work is
small: package init is 0.8 ms more (`--help` median 7.0 ms against 6.2 ms), and the V40 key
takes 0.47 ms. A third run alternated the two revisions, each `--list` straight after a Python
run. There HEAD's `--list` was the faster one (126-150 against 145-197). The `--list`
difference is within this host's noise; it is not a cost the merge adds. The win for
`--list` is on a real host, where F44's seat list is a Python start.
