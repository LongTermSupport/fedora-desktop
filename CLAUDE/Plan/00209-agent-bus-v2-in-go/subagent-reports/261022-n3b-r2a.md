  the uid and home of `agent1` or `agent2`, and the fixture passwd has both users.

  `systemd Stop <unit of t1>`. `TestAbsentStopsOnlyItsOwnSeatsUnit` replaces

  stay, and t1's copy is deleted.

- `faults_test.go`: `breakCopy` uses the seat key. `TestAbsentWrongPasswdFailsTheMember` is

### New tests (`seats_test.go`, `restart_test.go`, `kit_test.go`)

- Two seats of one user in one container: both added (`repo.1`, `repo.2`). Each has its own
  copy, unit and membership session. `guest check` runs once.
- Two users' seats on one checkout: a `ccy.env.local` owned by agent2 is accepted when both
  users' entries name the checkout, and refused when only agent1's does. Each bundle is placed
  as its own user.
- User move: the present phase defers with `whyOldUser` and leaves the entry alone. The absent
  phase parks, removes as the old user, deletes the copy and rewrites the entry (agent2,
  deferred, the same handle, `whyMoved`). The next present phase returns the seat as agent2.
  The deleted-old-user and missing-container cases are tested too.
- Retired join: DEFERRED `seat 1's account is deactivated; give the entry another seat`. The
  phase does not fail, and no bundle is placed.
- A join recorded before another container's place-bundle fails: the c2 entry keeps
  `repo.2`. Declared absent, it is parked and its entry dropped.
- Equal handles: two derived handles that are equal are both refused, and nothing is joined. A
  handle the record already holds refuses the newcomer only.
- `keyOwners.claim`: a seat may claim its own key twice and the same key in another container;
  a collision planted under the key is refused by name.
- Bad seats are refused at `validate` before a key is made (seat 0, seat 10000, a relative,
  root or unclean checkout). Another team's bad entry outside `--only-teams` fails nothing. A
  seat declared twice is refused.
- `Restart`: refused at `record` (Drift, 70) when there is no record, when the entry has left,
  or when the key belongs to another container or another seat. It finds t2's seat among two
  teams' records and ignores a stray file in the record directory. An unreadable record fails
  `record` without Drift. A recorded seat with no unit file is refused at `unit`.
- Kit sweep `/run` listing: a live session under a seat key the apply does not act on, or
  under the login run root, keeps the old kit. A name that `/run`'s grammar refuses is
  ignored. A `/run` that cannot be listed keeps every digest.

### guestroot flake (test only)

`sys_test.go`: the recorder retries a real EINTR on openat2, openat, read, write, getdents and
flock, and openat2's real EAGAIN, up to 64 times. The retry is inside the recorded call
(`unrecorded`, `unrecordedErr`), so a run's call count does not depend on load. An injected
error returns from `step` before the real call, so `TestOpenRetriesARacedResolution` still
covers the production retry. `TestRecorderRetriesARealInterruptOutsideTheCount` interrupts
openat2 for real through an `interruptingSys` and checks that the count does not change. The
sweep passed `-count=5 -race`. The flake was never reproduced, so this removes the likely
cause; it does not prove that cause.

## host/lxc exported API as built (for the probe and the admin wiring)

```go
func Apply(ctx context.Context, d Deps, req Request) (Report, error)
func Restart(ctx context.Context, d Deps, container paths.ContainerName, key paths.SeatKey) (err error)

type Target struct {
	Container paths.ContainerName
	Key       paths.SeatKey
}
type Request struct {
	Phase     Phase          // PhasePresent | PhaseAbsent
	OnlyTeams []paths.TeamID // nil: every team
	Members   []Target       // nil: every entry (--member C/K)
	Decl      declare.Declaration
}
type Deps struct {
	Root      string // host path prefix ("" on a host)
	LockDir   string // paths.AdminRunDir
	Clock     Clock
	LXC       Containers
	Pin       func(ctx context.Context, container string) (Root, error)
	Bus       func(ctx context.Context, r Root) (guestbus.Systemd, error)
	Roster    Roster
	Approvals declare.Approvals
	Origin    func(ctx context.Context, team paths.TeamID) (string, error)
	V1        V1Holdback
	Kit       paths.Digest
	HostKit   string
	HostUIDs  map[int]bool
	OwnerGID  int
	Bridge    string
	Refresh   func(ctx context.Context, team paths.TeamID) error
}
type Roster interface {
	Members(ctx context.Context, team paths.TeamID) (map[string]string, error)
	Join(ctx context.Context, team paths.TeamID, j Join) (Joined, error) // retired: errors.Is(err, apply.ErrRetired)
	Park(ctx context.Context, team paths.TeamID, handle string) error
	Reach(ctx context.Context, team paths.TeamID) ([]byte, error)
}
type Join struct {
	Op        string // apply.OpMemberAdd | OpMemberReturn | OpMemberReissue
	Prefix    proto.Prefix
	Seat      int    // the entry's own seat, add only (--seat)
	HumanText bool
	Handle    string // return and reissue
}
type Joined struct {
	Handle string
	Bundle []byte
}
type Report struct {
	Lines   []Line
	Summary string // printed LXC-SUMMARY\t<Summary>
}
type Line struct {
	Kind      LineKind // Changed | Skipped | Deferred
	Team      paths.TeamID
	User      paths.GuestUser
	Container paths.ContainerName
	Checkout  string
	Seat      int
	Key       paths.SeatKey
	Why       string
}
// String: <kind>\t<team>\t<user>@<container>/<repo>-<seat>-<key>\t<why>
type OfflineError struct { // exit 69, only for an explicit target
	Container paths.ContainerName
	Why       string
}
type Root interface { Alive; Close; Stat; ReadFile; ReadDir; ReadProcStat; ProbeLock; DialSocket; InitExe; Writer }
type Containers interface { Containers; State; InitPID; Addresses; Config; Guest } // lxccmd.LXC
type Clock interface { Now() time.Time; Sleep(ctx context.Context, d time.Duration) error }
type V1Holdback interface { Holds(ctx context.Context, r Root, u paths.GuestUser, team paths.TeamID) (bool, error) }
const SeatFreeWait = 60 * time.Second; const SeatFreeGap = time.Second
```

Errors the admin mapping needs: a `*host.Error` with `Drift: true` is 70 (refused by name). The
`Step` values are `validate`, `reads`, `roster`, `record`, `membership`, `unit`, `guest check`,
`guest remove`, `park`, `lock`, and for `Restart` also `state`, `pin`, `restart` (`Verb` is
`lxc restart`). `*OfflineError` is 69. `Restart` finds its seat in
`root+paths.LXCRecordDir`, in the one entry that has not left; none, or two, is `record`
Drift. Additions outside host/lxc: `paths.LXCRecordDir`, `guestfacts.ErrNoAccount` (wrapped
with `ErrRefused` by `Passwd`), and `guestfacts.SameMember(derived, recorded proto.Handle)`.
