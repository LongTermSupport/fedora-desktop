## Decisions and departures

- **A8 scope.** LX6 says a handle joined in the phase keeps the DEFERRED line. I applied that
  only before the bundle is placed, as the review proposed. A seat that is placed and then
  stops at `guest membership` already has its CHANGED `joined as` line, so it stays SKIPPED
  (`offline: membership pending`, `TestMembershipStopIsOfflineAndRerun`).
- **A9, the pin.** In the absent phase, a pin that fails after `lxc-info` answered running is
  still read as the container stopping. The review named only the `lxc-ls` and `lxc-info`
  failures.
- **A9, the probe.** I did not change the L3 probe (`Guests.running`). It is not in A9's list,
  and LP1 says a guest that cannot be reached is Stopped.
- **A10, the sleep.** A `Clock.Sleep` cut short by its context now fails the leaver, where it
  used to report the seat as held. nilerr flagged the old version, and a cancelled run is not a
  held seat.
- **A1, the roster read.** A failing `Roster.Members` fails only the leavers that needed a park.
  Leavers that are left or have no handle go on.
- **Simplification (one stage enum for `member`): declined.** It would rewrite `fail`,
  `offline`, `membership`, `unit` and `settle` across the whole phase. That is not small, and
  the B builder is working in the same tree at the same time. A3 and A8 are fixed directly,
  each with its own test. It is worth a follow-up slice.
