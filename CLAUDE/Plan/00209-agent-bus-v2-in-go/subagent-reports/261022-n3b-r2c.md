# n3b r2c report (Plan 00209 N3, slice n3b, part r2c: the admin verbs and the wiring)

Branch `feat/bus-v2-n3b-r2c`. Paths are under `src-go/internal/teamchat/`.

## What r2c built

- **Verbs** (`admin/lxc.go`, `admin/verbs.go`):

  - `lxc apply --phase absent|present [--only-teams T,...] [--member C/K]...`. stdin is the declaration, read under 1 MiB and decoded by `declare.Decode`. stdout gets each `lxc.Line.String()`, then `LXC-SUMMARY\t<Summary>` (left out when `Apply` fails in validate and returns `Report{}`), before the error.
  - `lxc restart --container C --key K` calls `lxc.Restart`. It reads and prints nothing.
  - `System.LXC func() (*lxc.Deps, error)`: nil gives exit 1, an error gives 78. `rootRuns` carries both verbs.
  - `lxcRoster` (implements `lxc.Roster`) runs `Members` over `ChildViewer.View`, and `Join`/`Park` through `memberWork`. A retired `ChildError` wraps `apply.ErrRetired`. `Reach` builds `{"v":1,"team","base_url","plain_http_hosts"}` from team.json.
  - `underLock` became `memberWork(ctx, sys, op, team, args) (work, error)`, with `work{doc, answer, bundle}`.

- **n3b-D3 exit mapping** (`admin/exit.go`): `decisive(err)` walks the joins depth first and returns the first leaf that is not an `*lxc.OfflineError`. The exit is 69 only when every leaf is offline; otherwise the usual mapping applies to that leaf. An offline member that is not targeted never changes the exit.

- **gap-20 split**: a stopped, untargeted member is shown as a DEFERRED `offline: container stopped` line and the apply succeeds for the rest. A stopped target alone exits 69. A stopped target plus a running target refused at config exits 70.

- **System.LXC** (`admin/wire/lxc.go`): `sync.OnceValues(m.lxcDeps)`.

  - `Pin` is `guestroot.Pinner{Proc, Kernel}`.
  - `Bus` is `Root.DialSocket("/run/systemd/private")`, then `guestbus.Dial`, then `guestbus.New`.
  - `HostUIDs` is `guestfacts.HostUIDs` over `/etc/passwd`.
  - `Kit` comes from `currentKit`: the root must be owned by `kitOwner` and not group- or other-writable, `current` a symlink owned by `kitOwner` whose target passes `paths.ParseDigest`.
  - `HostKit`, `Origin` (`health.Stamps.Origin`, new), `V1` (`v1NotBuilt`, names N6), `OwnerGID`.
  - The health tick's `Guests` is `lxc.Guests{Root, LXC, Pin}` (gap 10).

- **LP2** (`admin/serveview_test.go`, `TestServeMemberDisconnectedPostsOnceAndNotAfterLeft`, through `Serve` over fakehs). Cases that are new:

  - exactly one `disconnected` notice after 3 asks;
  - none after the member's own `left`: the answer is Posted true (`notice.Outcome.Found`, the goodbye already there), and the room holds no `disconnected` and one `left`;
  - a transient failure answers unreachable and the notices are unchanged.

  The existing `TestServeMemberDisconnectedPostsTheNotice` (asked twice, `slices.Contains`) is unchanged. The answer does not carry `Found`; a Posted true after a `left` is the design.

## Exported API and CLI as built

- `admin.System.LXC func() (*lxc.Deps, error)`.
- CLI: `lxc apply --phase absent|present [--only-teams T,...] [--member C/K]...` (stdin: declaration), `lxc restart --container C --key K`.
- `health.Stamps.Origin` is new. `health.GuestsNotBuilt` and `health.ErrGuestProbeNotBuilt` are gone (n3b-D4). `lxccmd.LXC` is now `{Runner execx.Runner}`.
- Exit codes: 0, 1 (seam unwired), 64 (usage and flag refusal), 69 (every leaf offline), 70 (drift, config, a record missing), 78 (seam error).

## Decisions

- Carried from the handoff: an invalid `--only-teams` team is 70 (`host.Error` Drift from validate) and has no summary, because `Apply` returns `Report{}`. `decisive` implements n3b-D3.
- **Removed `lxccmd.LXC.DesktopUID`** (lead's decision). `HostUIDs` (n3-D29) refuses every host passwd uid before any attach, and a zero left in the field read as root. The field, its `checkGuest` case and the "the desktop uid" refusal case are deleted. A host uid, the desktop user's included, stays refused through `HostUIDs`: `host/lxc/apply_test.go` case "host uid" (uid 1000, in `HostUIDs`).
- **n3b-D4: deleted `health.GuestsNotBuilt` and `ErrGuestProbeNotBuilt`** (no production caller). The tick's probe-error path stays covered by `TestTickRecordsAFailingGuestProbe`, which uses a test-local `failingGuests` probe that returns an error: the member is recorded offline with the probe problem and no notice is asked.
