# n2f part "wire": the health and element verbs, Env.Wire, the production System and main

Branch `feat/bus-v2-n2f-wire`. Commits: `20cf70d5` (health.Tick.One), `a1264409` (verbs and
Env.Wire), `54ae8a99` (package wire and a project-rule row), `68f3bd20` (main).

## What was built

- **`(*health.Tick).One(ctx, team) (Outcome, error)`** (VB2). It ticks one stamped team the way
  RunAll does, and takes the lock. A team with no stamp is an error. It shares the stamp lookup
  with Refresh.
- **admin**:
  - `Env.Wire func() (*System, error)` (WR1). `e.system()` uses Sys, else Wire. A failed wiring
    is 78, `the wiring: <err>`. `version` and a verb of the wrong class never call it.
    `ctl-child` serves through the wired Opener, and a failed wiring there is a failed answer.
  - `System` gains `Pin`, `CtlIDs`, `Health func() (HealthTick, error)` and `Home func(uid)`.
    `team apply` sets `Host.Pin`, `CtlUID` and `CtlGID` from them. A missing one is 78, naming
    the part.
  - `HealthTick` is an interface with RunAll and One.
  - `health --all` / `health <team>` (VB1, VB2): one stderr line per team (`oneLine`). Exit 1
    only when a team failed, or the tick itself failed. Any other arguments are 64, checked
    before the tick is made. A tick that cannot be made is 78.
  - `element check` and `element apply [--consent]` (VB3, VB4). UID is Getuid. Root is
    euid 0. The home comes from `admin.LookupHome` (os/user by uid, never $HOME). Approvals use
    FileApprovals and names use StatusNames, both under `Host.Root`. `--consent` runs
    WriteConsent first.
- **`internal/teamchat/admin/wire`**: `wire.New(digest)` (WR2) holds every adapter the brief
  lists. `wire.Bridge = "lxcbr0"`. Backup is `ErrBackupNotBuilt`, "backups are not built yet
  (C 3.12)".
- **main** (WR3): `newEnv` adds `Wire: wire.New(digest)`, and run calls it.
- **qa/rules/table.go**: a `dynamicNames` row for `admin.ExecChild.Ask`. The child part's
  `Name: spec.Path` failed the project rules (`go vet -vettool` of the driver). Now it passes
  over `./internal/teamchat/...` and `./cmd/teamchat-admin`.

## Decisions (where SPEC-n2f is silent)

| ID     | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| n2f-W1 | Building the System reads only `/proc/self/exe` (CS2) and checks the digest. Those two are the only wiring errors (78). Every other host read happens when a verb calls its seam: the bus connection, the ctl account (`CtlIDs`), the owner group (`OwnerGroup`, made once with `sync.OnceValues`), the pin (`Pin`) and the tick (`Health`, `Host.Status`, made once). A missing part therefore fails only the verbs that need it, at 78 or as their error, and never `element`, `ctl-child` or `team approve`'s other checks. |
| n2f-W2 | `Host.Pin`, `CtlUID` and `CtlGID` are no longer set by the wiring. `team apply` fills them from `System.Pin` and `System.CtlIDs` after the Fedora check (HF3) and before reading stdin.                                                                                                                                                                                                                                                                                                                                        |
| n2f-W3 | With no owner group, `Host.Status` is an adapter that returns "the status record: the owner group: …". Member verbs do not check the owner group before acting. The status refresh fails after the child's work, joined as today.                                                                                                                                                                                                                                                                                              |
| n2f-W4 | `Host.Approvals` is FileApprovals with GID -1 (it only loads). `team approve` still builds its own FileApprovals with the owner group's gid.                                                                                                                                                                                                                                                                                                                                                                                   |
| n2f-W5 | Every `element.ErrRefused` is 64: root, input, consent and target alike. A missing home is 1, as is any other failure.                                                                                                                                                                                                                                                                                                                                                                                                         |
| n2f-W6 | The `health` and `element` verbs build the System before they check their arguments, as every other verb does (TestEveryVerbEveryClass keeps "not wired yet"). The tick is made only after the arguments pass.                                                                                                                                                                                                                                                                                                                 |
| n2f-W7 | When the wiring fails, `ctl-child` answers it as a `failed` answer (exit 1), not a bare 78, because root reads only the answer. With no Sys and no Wire it still says "not served by this build".                                                                                                                                                                                                                                                                                                                              |
| n2f-W8 | `units.Manager.Close` is never called. The connection ends with the process, which runs one verb.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| n2f-W9 | `Network` and `Firewall` use `Proc` `"/proc"`. Under a test root it is `<root>/proc`.                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## Notes

- As root, the `element apply --consent` success path cannot be asserted: a file written by root
  is not owned by the fake uid. That assertion runs only when the tests run as a non-root user.
  The code path itself runs in both cases.
- Gates A and B held: no play, unit, tmpfiles or meta-deploy entry, and no install of any kind.
- No adversarial reviewer was run, because the brief asked for none. The coordinator reviews.
- Proposed design-text fix: WR2 should say that the pin, the ctl ids, the owner group and the
  tick are read when a verb first needs them (n2f-W1).
