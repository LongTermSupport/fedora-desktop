## The fix (11a6f1e6a): TIMEOUTs and the floor rule

n3d's TIMEOUTs are pending items in main, with `SentMS` set to the deadline plus the grace. This
member's clock makes them; the server never handed them. Under n3c's floor rule:

- **Owed:** `ownedFloors` pulled main's floor down to just below the TIMEOUT on the next batch.
- **Acked:** `raiseFloors` raised the floor to the TIMEOUT's time. That can be past what the server
  has handed. When the server is down, which is when TIMEOUTs fire, events posted during the outage
  before that time would fail `rejudge`/the floor when the server returns.

The fix keeps n3c's floor rule but leaves TIMEOUTs out of it: `fromServer(p)` in `seam.go`, used
by `ownedFloors` and `raiseFloors`. `TestATimeoutNeitherLowersNorRaisesTheFloor` (`outbox_test.go`)
was red on each half without the fix.
