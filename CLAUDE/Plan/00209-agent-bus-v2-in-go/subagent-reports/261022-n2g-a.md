## The exported API as built

- **paths** (`paths/restore.go`). Every path is absolute, and a backup number `n int64 <= 0` panics.
  - `RestoreRecord(t)`, `RestoreEpochFile(t)`, `RestoreConfig(t)`, in `root/<t>/`;
  - `BackupDir(t)`, `BackupTar(t, n)`, `BackupLastRun(t)`;
  - `RestoreLostFile(t, n)`, in `ctl/<t>/`;
  - `HomeserverPrivateBackups(t)`, `HomeserverPrivateBackupMeta(t)`, `HomeserverPreviousDatabase(t)`;
  - `HomeserverRestoreDatabase(t, n)` (the unit's view) and `HomeserverPrivateRestoreDatabase(t, n)` (root's);
  - `RestoreUnit(t)`, `RestoreCtlUnit(t)`, `RestoreUnitCredential(t)`.
- **teamlock:** `type Guard func(paths.TeamID) error`, `Unguarded`, `ErrNoGuard`, and
  `Take(ctx, dir, team, verb, wait, clock, guard)`, whose guard is the last argument.
- **restore:**
  - `Guard(root) teamlock.Guard`, `ErrPending`, `PendingError{Team}`. `admin.ExitCodeOf` maps `ErrPending` to 70;
  - `Child`, with `SecureArgs`, `CheckArgs` (with `Live()`), `SwapArgs`, `ExportArgs`, `Export{Count, FirstMS, EndMS; Truncated}` and `Epoch{RestoreEpoch, Rev}`, in `restore/child.go`.
- **host:**
  - `Deps.Guard`;
  - `Serve(ctx, d, team) error`, which fails as a `*host.Error` with Verb `serve`;
  - `BaseSandbox() []string`, a copy that keeps `%i`, and `TeamSandbox(t) []string`;
  - `ReadUnitsVersion(root string, team paths.TeamID) (paths.ServerVersion, error)`. A missing or bad `units.json` is an error. `Serve` reads the file through the same helper;
  - `RegKeyOf(config []byte) string`, which answers `""` when the config holds no key.
- **units:**
  - `State{Load, Active, InvocationID, NRestarts int64, Result}`;
  - `(*Manager).State(ctx, unit)`;

- **ctl / admin.Opened:**
  - `Opened.Restore RestoreFiles`, with `Swap(token, rooms, roster []byte) error`, `Finish() ([]string, error)`, `Revert() ([]string, error)` and `WriteLost(n int64, data []byte) error`;
  - `Opened.Staged func(ctx, port int, token string) (*matrix.Admin, error)`;
  - `admin.StagedWait` (60 s), `ctl.Config.Sleep` and `admin.Process.Getgid()`.
- **admin ops:**
  - `OpRestoreSecure|Check|Swap|Export|Finish|Revert` (`restore.secure` and the rest). Their exact args are in `restoreArgKeys`;
  - the Answer gains `Export *restore.Export` (key `export`) and `Epoch *restore.Epoch` (key `epoch`).
- **admin.RestoreChild** `{Live Child; Unit func(argv []string) Child}` implements `restore.Child`:
  - `Secure` always goes through `Unit(unit)`. `Check` with a nil unit and `Live()` args goes through Live, with null port and token. `Check` with a unit and staged args goes through `Unit(unit)`. A mismatch is refused before anything is asked. Swap, Export, Finish and Revert go through Live;
  - rooms are sent as `apply.EncodeRooms` and the roster as `RosterFile.Encode()`, both parsed to proto values. The team file is parsed from its bytes and must be an object;
  - each answer must pass `answerFits(op, a)`. A failed answer is a `*ChildError{Class, Message}`, and the `[]string` ops return the lines that changed before it beside the error. A nil `Unit` is a config error (78).
- **admin.UnitChild** `{Runner execx.Runner; Argv []string}` is a `Child`. It runs `Argv` as root (no credential) in `/`, with `CleanEnv` and the environment `PATH=/usr/bin:/bin` and `LANG=C` (RU3). The request goes on stdin. It is bounded by `ChildWait` and judged by `judge` (CS4). An `Argv[0]` other than `/usr/bin/systemd-run` is a config error, and nothing runs.
  - `askRun(ctx, bound, runner, cmd, req)` is now the shared tail of `ExecChild.Ask` and `UnitChild.Ask`.

## Decisions

- **RC8 reads the main room from the child's own `rooms.json`**, because the spec gives
  `restore.check` no rooms arg. If a backup's main room differs from today's, the verify fails
  closed: the staged server has no roster event in today's main room. The check also refuses a
  roster event whose sender is not the team's admin. **Proposed design fix:** give
  `restore.check` a `rooms` arg, the tar's `rooms.json` object as `restore.secure` and
  `restore.swap` take it, so the staged check reads the room the backup actually has.
  `CheckArgs` would gain `Rooms`, and the live form (RS7) would send today's rooms.
- RC1 checks the staged event's rev before it changes anything; a rev that is not above it is refused (70). A retired handle is
  kicked only where it is joined or invited, and deactivated only when it is found and active, so a repeat
  changes nothing. The random password is `crypto/rand.Text()`.
- RC3: the export's `end_ms` is `max(now, newest kept event)`. Each room is read backwards in
  pages of 100 until an event at or before `since_ms`. A room that passes the cap on its own is cut there,
  and the merge across rooms then keeps the newest events under 64 MiB.
- RC2 refuses a swap when any of the three files is missing, before it changes anything, because a revert could not
  restore a file that was absent.
- A restore op's file failure answers `failed` (1). A missing seam answers `config` (78).
- `units.State` carries `Load` (LoadState), beyond the spec's four fields, for RS3's "poll until
  not loaded". A unit that cannot be loaded gives `{Load: not-found, Active: inactive}`.
- `host.Serve` always runs daemon-reload, because what systemd has loaded cannot be read from the files. It checks the
  bound addresses as well as readiness, and it never enables the unit.
- `BaseSandbox` is a function that returns a copy. `TeamSandbox` substitutes `%i`, because a transient unit's
  properties are not expanded (n2g-D18). `StateDirectoryMode` and `IPAccounting` are included in
  the sandbox list. `LoadCredential` and `Environment` are left out.
- `admin/wire/wire.go` (C's file) gained `Guard: restore.Guard(root)`, with a test: without it, a nil guard would break every
  production apply.
- **UnitChild's environment** is `PATH` plus `LANG=C`, as RU3 says. The a4 handoff had said "PATH only", and RU3
  wins. Its working directory is `/`.
- **UnitChild refuses an `Argv[0]` other than `/usr/bin/systemd-run`**. Its `Name` comes from the argv at run
  time, so it has a `dynamicNames` row in `src-go/qa/rules/table.go`, as C's `restore`
  `unitCommand` has. The check means the row can only ever excuse systemd-run.
