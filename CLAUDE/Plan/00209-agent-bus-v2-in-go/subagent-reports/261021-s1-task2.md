## What changed

- `src-go/internal/declare/declare.go`, `lxc.go`: Declared, Limited, Undescribed,
  ElementTeams, TeamsFor, Choices, GithubRemote, Address, Settings, NextSteps and LxcMembers
  call `bus/declare`. The file is read with `busdeclare.Read(c.File, os.ReadFile)`; no
  `ReadFile` field was added, because every test uses real files. Team, DescriptionState,
  Limit, Undescribed, Profile, Standing, Choice, Setting, SettingState and LxcMember are type
  aliases. I compared LxcMember and Setting field by field; they are identical. Their constants
  are re-exported.
- `fromReader` turns a `*busdeclare.Error` into `&Error{Code: e.Code(), Stderr: "declare: " + e.Message, cause: err}`.
  A crash comes out as code 1, which is `ErrFailed`.
- Settings still refuses a value that is not JSON, with the old text: `SETTING <key>: the value is not JSON: "<value>"`.
- Overview reads Declared in-process, then makes one `declare status` run. A refused file
  starts no process.
- Status, the edits, check, check-address, suggest-team and the lxc-\* subcommands other than
  lxc-members are unchanged.
- I deleted parseTeams, parseDescription, the LXCMEMBER parser and orNone, and rewrote the
  package doc.
- teamtest gains:
  - `WriteHostVars` and `WriteHostVarsIfAbsent`. Interactive writes an empty host_vars when
    none exists, replacing its old empty limited and undescribed scripts.
  - `OnDeclareEdit`: a faked Python edit that rewrites the file, so later reads see the edit.
  - `HostVarsWithLxc` (the deduplicated helper from lxcadd and roles), and `HostVarsAlpha`,
    which Populated writes in place of DeclaredAlpha. DeclaredAlpha is deleted.
- `OnDeclare` now panics when given a read subcommand. A grep confirms nothing else scripts a
  read.
