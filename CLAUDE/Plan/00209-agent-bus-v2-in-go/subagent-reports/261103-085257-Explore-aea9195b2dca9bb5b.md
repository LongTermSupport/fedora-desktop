I found where the team-join questions are asked. The "change one at a time" screen you describe does not exist: Quick Launch is a single Y/n for everything.

**1. The team-join questions**

The bash launcher starts them. `ccy_launch_teams` (`files/var/local/claude-yolo/claude-yolo:863-884`) runs `ccy-teams choose-teams --type=podman` (line 870) when attended and the list is empty or names a team without a seat. The automatic join is the Quick Launch path, which calls `ccy_launch_teams` again (line 1286). `ccy_seats_check` (`lib/agent-bus-seats.bash:45`) only validates the list through `agent-bus seat check`; it asks nothing.

The questions themselves are Go, in `src-go/internal/teams/chooser/` and `choose/`. In order:
1. **Team list** (only with a bare `--teams`): an fzf multi-select in `take`, `chooser/list.go:29`. It is skipped when exactly one team covers this checkout and its homeserver is up (lines 30-34). It can also run the create wizard.
2. **Scope**, per team that does not cover this repo: "X does not trust R. Add R (any branch) to it?" in `settle`, `chooser/widen.go:31` (question at line 51).
3. **Seat**, per team: "Team T: which seat does this session take?" in `pickSeat`, `choose/choose.go:290`, called from `PickSeat` at line 99.
4. **Role**, per team: `offerRole`, `choose/choose.go:319`. It is skipped for a new seat or one with no member yet.
5. **Element consent**: `consent`, `chooser/consent.go:45`. Only for `--type=host` (cc, not ccy), and remembered once per user in an acceptance record.

`flow.LaunchTeam` (`flow/kit.go:65`) only supplies the screen heading. It is used at `chooser.go:189`, `widen.go:50` and `widen.go:136`.

**What is remembered:** only the final seat list, saved as `LAST_TEAMS` in `.last-launch.conf` (`claude-yolo:3400`). Seat and role answers are not remembered. The seat picker's preselected default (`choices.Default`) comes from `agent-bus seat choose` (`helpers/agent_bus/cli.py:217`). I did not check whether that default reflects the last choice.

**2. The token and SSH "defaults summary" screen**

Quick Launch is in `claude-yolo:1220-1330`. It runs only when no token, SSH, or network flag was given. It reads the saved file with `load_launch_config` (`claude-yolo:534`), shows Token, SSH Key, Network and Team, and asks once: "Use same configuration? [Y/n]" (`lib/common-pure.bash:40`). Y takes everything. n prints "Reconfiguring with interactive prompts...", and every question is asked again through `select_token` (`lib/token-management.bash:1060`) and `discover_and_select_ssh_keys` (`lib/ssh-handling.bash:426`). The file is written at `claude-yolo:3389-3404`.
