# n3e-sl: the status line prints nothing with no session

Defect: `teamchat status-line` wrote a lone newline when there was no inner line and no segment,
so Claude Code drew a blank row.

Fix: `statusline.run` returns ExitOK without writing when the text is empty. Every empty path
(no session, no settings, the loop guard, a team list that is empty or filtered to nothing, a
free link with no run dir) goes through that one check, so no other path prints an empty line.

Tests (red first, seven failing, then green): the pins of a lone newline in statusline_test.go
became empty (a `rows` helper serves the table tests), and kit PK1 now expects zero bytes with no
session.

Docs: SPEC-n3.md SL1 and DESIGN-v2-B-member.md 2.9 item 2 say stdout is zero bytes, never a lone
newline.

Checks: race and shuffle green over member/...; statusline 98.0%, kit 93.3%; golangci clean
untagged, with tuwunel and with busfailpoints.
