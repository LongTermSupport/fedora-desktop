- Without the `busfailpoints` tag, `Hit` is empty.

### wire: the control socket (`control.go`)

```go

	KindClaude = "claude"; KindToken = "token"; KindDesired = "desired"; KindEnd = "end"; KindReady = "ready"

func (c *Conn) Close() error                 // unblocks a Recv
```

- **The wire format.** Each message is one strict JSON object, `{"<kind>":{body}}`. It is decoded
  by request.go's `decodeStrict` (no unknown key, no key in another case, no null where a value
  is needed), then by the kind's rules.

- **The kind's rules.** The `state.*` closed sets apply, plus these:

  | Body         | Rule                                                                                            |
  | ------------ | ----------------------------------------------------------------------------------------------- |
  | launch       | `cwd` and `claude_config_dir` are absolute and clean, with no NUL                               |
  | add          | `proto.ValidSeat`; `removed_user_ids` is a list, never null                                     |
  | add, removed | each user id is an agent's (`proto.AgentHandle`) on `paths.ServerName(team)`, at most 128 bytes |
  | remove, owed | the txn matches `^tc[0-9a-f]{32}$`                                                              |
  | pid, claude  | pid > 0 and start_ticks >= 0                                                                    |
  | token        | 1-1024 bytes of `\x21-\x7e`                                                                     |
  | desired      | report.json's rule: code null exactly when applied; code json, schema, version, seat or missing |
  | end          | status 0-255                                                                                    |
  | state        | `proto.ParseHandle(handle)`; last_sync_ok_ms null or > 0; pending >= 0                          |

- **Send.** It refuses with `ErrProtocol` before anything is written when the message breaks a
  rule:

  - Kind does not match the one set body, or no body or two bodies are set.
  - A body breaks its rules.
  - The message is over 64 KiB.
  - An add has no fd, or any other kind has one.

- **Recv.** It returns `ErrProtocol` for:

  - `MSG_TRUNC` or `MSG_CTRUNC`, with room for 4 fds;
  - a message over 64 KiB;
  - a message that is not strict or not one kind;
  - the wrong fd count.

  Every fd that a refused message carried is closed. A refusal leaves the socket readable. The
  caller decides whether to close the link.

- **Close-on-exec.** Go's `ReadMsgUnix` sets `MSG_CMSG_CLOEXEC` on Linux.

## Deviations from the brief and the review notes

01. **`View`'s fields are renamed** from `Seen`/`Related`/`OwnPings` to `SeenIDs`/`Events`/`OwnPings`.
    - Go forbids a field and a method of the same name, and View has the `Seen` method that makes
      it a `proto.Lookup`.
    - `Events` names `proto.Lookup.Event`'s map.
02. **`Msg.String`, not `Format`.** `go vet`'s stdmethods check reserves `Format` for fmt's
    signature. `Token` also has `String` and `GoString`, so `%v`, `%+v` and `%#v` all redact the
    token.
03. **`wire` imports `state`**, for `state.Process` (pid, claude) and `state.ReportDesired`
    (desired). There is no cycle: state imports only lock, homefs, paths and proto.
04. **`Pair()` returns `(*os.File, *os.File, error)`**, not named results, because the linter
    (`nonamedreturns`) forbids named results. The keeper's end comes first.
05. **`ErrNotControl`** is an added error, from `NewConn`.
06. **`Kinds()`** and the **`End*` constants** are added. The constants are the closed set of
    `End.How`, which `team.End.How` reuses.
07. **`state` drops `link` and `session_started`, and gains `handle`** (notes 5 and 6). The
    session-level `started {}` is `KindStarted`.
08. **`Recv` does not close the socket on a refusal.** The caller closes the link, as n3c-D3
    says. `Recv` only refuses the message and frees the message's descriptors. A test shows the
    next message is still read.
09. **No direction check per kind.** A Conn does not know which end it is, and claude and token
    travel both ways. Each side ignores a kind it never receives, or refuses it in its own
    handler (P3 and P4).
10. **`Health.LastSyncOKMS` is `int64`, 0 before the first sync** (note 10's type). The link maps
    0 to `null` in `wire.State.LastSyncOKMS`, which refuses 0.
11. **The txn rule.** `remove` and `owed` carry the store's grammar (`^tc[0-9a-f]{32}$`,
    n3c-D14 and D18). A `tc-disc-*` txn is refused there.
