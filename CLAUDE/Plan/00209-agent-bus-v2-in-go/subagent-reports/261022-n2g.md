## API as built

The parts' reports list each exported name. This session changed the following:

- `restore` engine: the `serverLost` wrapper is removed, so a child's failure against the live
  server is returned as it came. RS4's backup finding the server not running becomes
  `serverLostError`, which matches `matrix.ErrUnreachable` and hides `backup.ErrNotRunning`.
  The pre-backup is now its own method, `preBackup`.
- `restore.Merge` (RM12): an offline pending `member.retire` retires the handle even when backup
  N does not hold it.
- `health` (HB3): `restartLocked` reads the restore record again under the lock and does not
  restart while one exists.
- `matrix/tuwunelhs` (test helper, `-tags tuwunel`) adds the following:
  - `Options.Args`, the arguments after the command;
  - `Server.Stop(sig)`, which stops the server by SIGTERM or SIGKILL and waits for it to end;
  - a cleanup that accepts the test's own SIGKILL.
- `admin` test world: `bareWorld`, `world.base`, `url()` and `stagedURL(port)`. With `base` set,
  the member and staged clients reach the real server.

## Decisions (n2g-D1 to D21 are in SPEC-n2g.md section 13; new here)

- **n2g-D22.** RS15's 69 means only a homeserver that is really unreachable: a matrix
  `ErrUnreachable`, a child's `unreachable` class, `backup.ErrLost`, or RS4's not running. A
  live child that ran and answered keeps its own class's code (refused 70, config 78,
  failed 1).
- **n2g-D23.** The RT tests run in `package admin`, as the handoff designed. Apply's backup step
  sees the real server's database, so the world marks the unit active and the step does not
  try to start it.
- **n2g-D24.** `backup --all` keeps BV2's exit 1 when any team failed. The owner's rule is met
  because a team that is down is shown and never stops the teams after it.
