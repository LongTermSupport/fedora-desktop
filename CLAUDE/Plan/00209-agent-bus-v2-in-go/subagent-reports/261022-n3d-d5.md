## What was built

The CLI side of the three sends, in P6's `member/client`. `client.request` gains a case for
`wire.OpReply`, `OpSay` and `OpPing`, which calls the new `sendArgs` (`send.go`). That builds
D1's args and, where the verb has one, the text for `Request.Stdin`. Everything after that is
P6's path, unchanged: the 30 s `wire.Deadline` on `clock.Boot()`, `kit` from `cli.Env.Digest`,
one connection, the records copied to stdout, the error object copied to stderr, the exit taken
from `done`, and LN3's no-link answers. A send has `wait == 0`, so it never reconnects.

- **Args.**

  - `say` sends `SayArgs{Team, To, ToCoordinator}`.
  - `ping` sends `PingArgs{Team, Verb: Args[0], Ref: Args[1] or nil, To, ToCoordinator, Branch: --branch or nil}`.
  - `reply` sends `ReplyArgs{Team, ID: Args[0], Verb: --verb, Ref: --ref, ToCoordinator}`.
  - `Team` is `inv.Team`, which is null when `--team` is not given.
  - `To` is `--to` split on commas. Without `--to` it is `[]`, never null.

- **stdin** (n3d-D15, n3d-D28) is read by `say` and by `reply` without `--verb`, in this order:

  1. A terminal on stdin (`term.FileIsTerminal`) is 64 `usage`, found before anything is read.
     The message names "text on stdin" and gives an `echo text | teamchat <verb>` example.
  2. At most `proto.MaxText+2` bytes are read.
  3. One trailing `\n` is removed.
  4. Over 4096 bytes is 10 `size`. Empty is 10 `empty`. Not UTF-8 is 10 `schema`.
  5. A failed read is 1 `internal` ("read its stdin").

  `ping` and `reply --verb` never touch stdin and send `stdin` null.

- Every text refusal returns before any connection is made.

## Decisions

1. **`To` is `[]` when no `--to` is given, not null.** D1 accepts both. One form makes the
   bytes deterministic, and D6a can read `len(To) == 0` either way.
2. **The client checks only the text.** The verb rules, `ack`/`nack` given to `ping`
   (n3d-D15), the 16-addressee bound (n3d-D5), `--to-coordinator` together with `--verb`
   (n3d-D14) and a TIMEOUT id (n3d-D26) are all the engine's, D6a's and D6b's. The client
   frames them faithfully and copies the answer. Not every caller is this CLI, so one judge
   keeps the rule in one place.
3. **The deadline starts after stdin is read.** A slow pipe does not use up the link's 30 s.
4. **The terminal check is `term.FileIsTerminal`.** It is the repository's existing predicate:
   a character device that is not /dev/null. The test uses a real pty master, not a fake.
5. **The `world` test fixture gains a `stdin io.Reader` field**, passed through `cliEnv`. This
   was the only change to an existing test file.
