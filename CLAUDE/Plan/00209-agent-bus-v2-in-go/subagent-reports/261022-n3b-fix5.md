## C1: no errno below the guest root is the host's

- **Change:** `guestroot/bound.go` `guestFault` no longer has the case for `EMFILE`, `ENFILE`
  and `ENOMEM`. Every error of a call below the pinned root is `ErrGuest` unless it is already
  classed (a refusal, a cap, a path not there, the root closed) or is a connect the guest's
  socket did not answer (`*net.OpError`, the bus down). Host faults are only the errors before
  the pin and the host's own /proc reads (`InitExe`, the pidfd poll), which are outside
  `bounded`. A real host exhaustion therefore fails each member alone, and the phase goes on,
  as ruled. The doc comments of `ErrGuest` (`root.go`) and `refused` (`apply.go`) are changed
  to match.

- **No change in `lxc`:** `placeKit` (`kit.go:131`) and `readsFailed` already route an
  `ErrGuest` to the member: `runParents`/`runsOf` take it as `refused()` and keep every digest,
  and `member()` refuses that seat alone. The defect was the classification, and it is fixed in
  the one place.

- **Red test:** `guestroot TestAnErrnoBelowTheRootIsTheGuests` now requires `ErrGuest` for every
  errno it plants. Without the fix it fails 69 rows, which is every op of every call for each of
  EMFILE, ENFILE and ENOMEM.

- **The member-only proof:** `faults_test.go` `guestErrnos` now holds EMFILE, ENFILE and ENOMEM
  beside EACCES and EIO. So these tests run once for each of the five:

  - `TestKitSweepListingFaultKeepsEveryDigest`: no seat fails, and the old kit is kept.
  - `TestCheckoutReadFaultFailsThatSeatAlone`: seat 1 is refused at the reads, and the other
    checkout's seat joins.
  - `TestLockProbeErrnoIsNotFree`: a probe that failed, never a free seat.

  These lxc tests plant errors already classed as guestroot now classes them. So they are not
  red without the guestroot change. Their red proof is the guestroot table.

## C2: the stall memo is keyed per seat

- **Change:** `apply.go` `guestBox.memos` is a `map[boxSeat]*guestroot.Memo`, where `boxSeat`
  is `{checkout, seat}` from `m.id`. The box is one container, so the key is
  (container, checkout, seat). `rootOf` gives each seat its own memo. A stall under one
  checkout fails that seat alone, in the reads and in the unit step.

- **Test:** `TestAStallFailsOnlyItsSeat` replaces `TestAStallIsWaitedOutOncePerUser`. It sets
  up these seats:

  - agent1's seat 1 on the stalled checkout `/srv/agent1/src/repo`.
  - agent1's seat 2 on a healthy checkout `/srv/agent1/src/zrepo`.
  - agent2's seat 3 on `/srv/agent2/src/repo`.

  Seat 1 does not join. Seats 2 and 3 join. The bound is waited out once (`waits == 1`).

- **Red before the change:** seat 2 had no joined entry, because agent1's memo answered its
  checkout read "was not tried: ErrStalled".

- **Cost accepted:** two seats on the same stalled checkout now each wait out one bound. A
  failed checkout read is not cached, and their memos are separate.
