### `member/client`

```go
func Main(verb string) cli.RunFunc                                 // recv, wait, inbox, status, verify, history
func SeatDisconnected(e cli.Env, inv cli.Invocation) term.ExitCode // "seat disconnected"
func Reach(e cli.Env, inv cli.Invocation) term.ExitCode            // "reach"
```

**`SeatDisconnected`** (EN5):

- It opens `homefs.Open(filepath.Dir(--bundle), Owned)`, then `bundle.ReadPairAt(root, dir, nil)`.
- `--seed` goes through `paths.ParseRunID` (64 `usage` if bad) and `--since` through
  `ParseInt`.
- It builds `matrix.NewMember` from the bundle's `base_url`, `plain_http_hosts` and token, then
  calls `notice.Disconnected` with these values:
  - Server is `server_name`;
  - Team and MainRoom come from the bundle;
  - Handle is `proto.Localpart(user_id, server_name)`;
  - Run is the seed, and SinceMS is `--since`.
- Exits:
  - 0 when the notice is posted or found;
  - 0 with one stderr line when it cannot be posted, of the form
    `teamchat: seat disconnected: no notice for run <seed>: <Why>`;
  - 20 `unreachable` for a transient failure, the 30 s bound, or a torn pair;
  - 78 `bundle` for a missing or refused pair, or for a parent directory that is missing, a
    link, or writable by others.

**`Reach`** (n3c-D16):

- The layout is TEAMCHAT_RUNTIME's when that is set. Otherwise it is `HomeLayout($HOME, $XDG_RUNTIME_DIR)`.
- It opens `homefs.Open(layout.State(), Private)` and reads `layout.Seat(T).Bundle()` with the
  `seat.MaxBundle` cap, then calls `seat.DecodeMemberBundle`. The bundle's team must be T.
- It builds `matrix.NewMember` with the placeholder token `"unused"`, then calls `Versions`
  within 3 s on the clock.
- It prints nothing. Exits: 0, 20 `unreachable`, or 78 `bundle`.

## Decisions

- **The ends set no presence; the link already does.** `link.go` `finish` and `leave` set each
  team offline after `End` and before `Leave`, so a second call would be a duplicate.
- **`notice.Roster` is exported.** The ends call it when `Notices.Roster()` is false, so
  `notice`'s `stateEvents` is not copied. W may switch it to `proto.StateEvents`.
- **The `back` txn is `tc-back-<run>`.** It is posted only when `LatestOwn` from 0 is
  `disconnected`. That makes it once per disconnect, and never after a `launch-failed` (EN4).
- **Records are buffered when the link closes before done.** The client copies a link's records
  to stdout only once the done arrives. A close before done copies nothing, so the link returns
  the unacknowledged records.
- **A link gets 5 s of grace.** A link that never answers is cut off at the request's deadline
  plus 5 s.
- **A failed stderr keeps the exit in `seat disconnected`.** The brief named EIO, EBADF and
  EPIPE. The project rule is that a failed write keeps the exit, as `exits.Write` already does,
  so any failed stderr write keeps the exit. The test covers all three errnos.
- **A torn pair in `seat disconnected` is 20 `unreachable`.** Code `unreachable` is the only
  code of exit 20. The message says the next pass reads the pair again.
- **`reach` reads with the `seat.MaxBundle` cap (16 KiB), not 64 KiB.** That is seat's own
  cap, so it is defined in one place, and nothing larger decodes anyway.
- **`reach` has two exits beyond 0, 20 and 78 `bundle`:**
  - a TEAMCHAT_RUNTIME that names no session is 69 `no-session`, the same as the other client
    verbs;
  - with no TEAMCHAT_RUNTIME and an unusable HOME or XDG_RUNTIME_DIR, it is 78 `runtime`,
    which is still exit 78.
- **The clock bounds are tested through `hsDeps.armed`.** It is a test seam that runs once the
  bound is armed on the fake clock, and the tests use it to move the fake clock past the bound.
  The matrix client's retry wait is `hsDeps.wait`; nil in production means matrix's own.
- **Two branches of `seat disconnected` cannot be reached with a bundle that decodes.**
  `NewMember` refuses only what `seat`'s own bundle check refuses, and the same holds for a
  user id off its server. The branches are kept anyway, as 78 `bundle`.
