## What changed

1. `wait` at its deadline (or any end of its context) exits 4 `timed-out` with no records and no team
   (`engine/recv.go`: `waitTimedOut`, used by `wait` and `done`). The exit and code were already in
   the exits table (`ExitTimedOut`, `CodeTimedOut`, class wait). Default 110 s and maximum 3600 s
   unchanged. Tests: `TestWaitAtItsDeadlineTimesOut`, and the ended-context case in `serve_test.go`.
2. The `teamchat.floor` marker carries the store's main-room floor.
   - `team.Engine.Persist` now answers `(mainFloor int64, err error)`: the floor `ownedFloors`
     left in the store after the write. The floor rule has one home (`engine/seam.go`, now `engine/storewrite.go`).
   - `teamsync` `commit(j, f)` takes that floor as the marker's floor, whenever it differs from the
     session's floor. It follows the store both up and down, so it is never moved back except by
     the store's own lower floor. An empty batch with no persist leaves it alone.
   - Tests: engine `Persist` returns 99 with items owed and 500 with none;
     `TestTheMarkerStaysBelowAnOwedItem` (teamsync) puts the marker at owed-1 and keeps it there
     after a later quiet batch. The coalescing and flush tests use a new `quiet` helper, since
     every mention now owes an item. The Tuwunel sync test now expects owed-1, and that a second
     link with no store finds the owed mention again.
3. Spec text: n3c-D7 row (exit 4), W-D1 after LN1, W-D2 after LN3, in `SPEC-n3.md` and the handoff.
   Correction (261022-n3c-docs.md): the n3c-D7 row went into the handoff only; SPEC-n3 gained it, with n3c-D1 to D24 and W-D3, in the docs part.
