## 1. Blocker: (b) only when the missed entry was due

**Defect class.** A classifier draws a conclusion from the fact that a store entry exists, without
checking that the entry's own preconditions held. Here the precondition is that `declareMissing`
runs only after 180 s of quiet. **Detector:** no analyzer or semgrep rule can express this. Whether
a branch checks the right domain precondition is a question of meaning, not syntax. So it is said
here and fixed conventionally. No other P2 reading branch rests on an unchecked entry: the
awaiting branch's precondition (a recv hands out only an item handed to nobody) holds by
construction.

**The clock.** `state.Store` has no clock of its own. `Missed.AtMS` is the engine's boot-clock
time when it declared the entry missing (`settleProof`, `now.Milliseconds()`). `Awaiting.AtMS` and
`StopMS` are on the same clock. `dueAt` is `min(write + 1 h, max(stop, last growth) + 180 s)`, and
stop is never earlier than the write (`deliverloop.go`: the stop equals the write when the session
is idle, or is set at a later Stop). So a declaration that was due always comes at least 180 s
after the delivery's write. The harness now reads `clock.System().Boot()` (CLOCK_BOOTTIME, one
clock per kernel, shared with the link process) in `newPT1Runner`, before the world starts. It
carries this as `pt1Runner.startMS` into `pt1Seen.startMS`. Each snapshot now also carries
`missedAt` (nonce to `Missed.AtMS`, filled by `pt1SnapOf`).

**The rule** (`pt1Classify`, `pt1_model_test.go`):

- A nonce found in both `missed` and `awaiting` before the recv reads **ambiguous**: the store
  contradicts itself.
- A nonce in `missed` with `missedAt < startMS + pt1QuietMS` (180 000) reads **production**,
  "declared missing before due".
- Any other missed nonce reads **harness**, as before.

`pt1QuietMS` is a test constant that mirrors `engine.quietAfter`, which is unexported. Its comment
points at the engine constant.

The record also prints `run started at N ms on the boot clock`, and each missed nonce as
`<nonce> at <AtMS> ms`. A reader of a failing seed can therefore check the judgement themselves.
