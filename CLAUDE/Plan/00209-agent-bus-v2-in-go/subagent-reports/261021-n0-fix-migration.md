## Re-checks the lead asked for

**INT3 (0b498397, a v1 name over 22 characters migrates under a short id).** Four defects found
and fixed (D 3.5, 3.9, 5.1, 5.4 M0, 5.10, 7.2, 12; DESIGN-v2.md INT3 row):

1. A later v1 team could be named after a migrated team's short id, and C's rule ("an id also in
   `agent_bus_teams` is accepted while the migration is at `preflighted` or later") would then
   accept the clash, so one string named two teams. Now a v2 id equal to a v1 name is accepted
   only when a set record pairs that very v1 name with that id, and ccy-teams refuses a new v1
   team named after a v2 id.
2. The id was required only for names over 22 characters; a v1 name equal to an existing v2 id
   also needs one. The rule is now "when the v1 name is not free as a v2 id".
3. A short id whose set rolled back had no stated resolution. It now resolves to nothing, naming
   the v1 team, and the same v1 team may reuse it.
4. The v1-name lookup had no end. Retirement step 3 rewrites the old seat strings to ids, so the
   lookup can be dropped.

text: 2 (receipt and join cuts flagged), 4 (literal `reject with tcp reset` rules per family),
