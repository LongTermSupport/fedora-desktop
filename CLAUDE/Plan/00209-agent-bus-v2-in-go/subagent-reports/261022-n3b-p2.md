### `internal/teamchat/host/lxc/guestbus` (imports godbus, `paths` and std)

```go
type Systemd interface {
	Reload(ctx context.Context) error
	Start(ctx context.Context, user paths.GuestUser) error
	Restart(ctx context.Context, user paths.GuestUser) error
	Stop(ctx context.Context, user paths.GuestUser) error
	ResetFailed(ctx context.Context, user paths.GuestUser) error
	Close() error
}

const (
	CallWait   = 30 * time.Second
	MaxMessage = 1 << 20
)

var (
	ErrTooLarge  = errors.New("guestbus: a message over its cap; the connection is closed")
	ErrMalformed = errors.New("guestbus: systemd's reply is malformed")
	ErrSystemd   = errors.New("guestbus: systemd refused")
	ErrGone      = errors.New("guestbus: the guest's systemd is gone")   // added
	ErrNoUser    = errors.New("guestbus: no guest user")                 // added
)

type SystemdError struct{ Name, Message string }   // added; errors.Is(e, ErrSystemd)
func (e *SystemdError) Error() string
func (e *SystemdError) Is(target error) bool

type Conn interface {
	Call(ctx context.Context, path dbus.ObjectPath, method string, args ...any) ([]any, error)
	Close() error
}

func Dial(ctx context.Context, c net.Conn) (Conn, error)
func New(c Conn) Systemd
```

- **The calls.** Each one goes to `org.freedesktop.systemd1.Manager.<Method>` at
  `/org/freedesktop/systemd1`, with destination `org.freedesktop.systemd1`. `Reload()` and
  `ResetFailedUnit(unit)` must answer an empty body. `StartUnit`, `RestartUnit` and `StopUnit`
  take `(unit, "replace")` and must answer exactly one `dbus.ObjectPath`. Any other reply is
  `ErrMalformed`, naming the method. The unit is always `paths.SessionUnit(user)`. A zero user
  is `ErrNoUser` and is not sent (`paths` would panic on it). Each call runs under
  `context.WithTimeout(ctx, CallWait)`.
- **Error classes.** P4's offline classifier reads these:
  - a D-Bus error reply, as the `dbus.Error` value or `*dbus.Error`, is a `*SystemdError` that
    carries the error name and the first string of its body (`errors.Is(err, ErrSystemd)`);
  - `io.EOF`, `io.ErrUnexpectedEOF`, `io.ErrClosedPipe`, `dbus.ErrClosed`, `net.ErrClosed`,
    `ECONNRESET` and `EPIPE` are `ErrGone`, which wraps the cause;
  - `ErrTooLarge` and context errors (`context.DeadlineExceeded` at `CallWait`) are passed
    through as they are. They are not `ErrGone`, and P4 decides what they mean.
- **`Dial`.** `c` is wrapped in the capped transport, then `dbus.NewConn` runs with
  `WithContext(life)` and `Auth([AuthExternal("0")])`. There is no `Hello`. If `ctx` ends
  first, a `context.AfterFunc` cancels `life`, godbus closes the connection, and the error
  wraps `ctx.Err()`. Every failure closes `c`. The production `Conn.Close` cancels `life` and
  closes the godbus connection.
- **The capped transport (`capped`, unexported).** The byte stream is never changed.
  - **Before the client's own `BEGIN\r\n`:** this is the SASL phase. Every incoming line,
    CR LF included, is at most 512 bytes. A read that holds a longer line is refused whole, so
    godbus sees none of it.
  - **After `BEGIN`:** the transport reads each message's 16-byte fixed header ahead with
    `io.ReadFull`. The endianness byte must be `l` or `B`, and the version byte must be 1;
    anything else is `ErrMalformed`. The length is `align8(16 + fieldsLen) + bodyLen`, in
    int64, so a uint32 sum cannot wrap. A length over `MaxMessage` is `ErrTooLarge`. Each
    message is passed on only up to its end, so the next header is always judged before any of
    its bytes reach godbus.
  - **`BEGIN` across writes:** it is detected from whole lines however the writes split them.
  - **After a refusal:** the connection is closed (once), and every later `Read` returns the
    same error.
- **The tests.**
  - On a fake `Conn`: each method's path, method name and arguments; every wrong reply shape is
    `ErrMalformed`; refusals keep their error name; the `ErrGone` set; and the `CallWait` bound,
    over a fake that blocks until its context ends. The test passes a 1 ms bound, does not
    sleep, and checks that `New` uses `CallWait`.
  - On an in-memory connection: bytes pass through unchanged in pieces of 1, 7, 16 and 4096;
    a read stops at the end of its message; a message over the cap is refused through its body,
    its fields, its padding and a uint32 sum, and the underlying reader is shown to have given
    up exactly 16 bytes; a message exactly at the cap passes; a bad endianness or version byte
    is refused; a truncated header is refused; and `Close` closes once.
  - Over `net.Pipe`, against a fake systemd peer that speaks the server half of SASL by hand
    and encodes its replies with godbus's `Message.EncodeTo`:

    - the reply to a `Restart` has a header with body length `MaxMessage`. The `Restart` fails

    - a cancelled context ends the dial with `context.Canceled`;

## A fact P4 and host check H-C9 need

godbus's `AuthExternal` sends `AUTH EXTERNAL` with **no initial response** (vendored
`auth.go`, which writes `AUTH` and the mechanism name only), so the "0" is never on the wire.
The server answers `DATA`, the client answers an empty `DATA`, and sd-bus authenticates from the
socket's `SO_PEERCRED`. Uid 0 is therefore a fact of the process that runs as root, and not a
claim the client makes. The fake peer speaks exactly this exchange. A real systemd is proven only
by H-C9 on the host (gate A).

## Changes from the handoff's signatures, with the reasons

- `ErrGone` and `*SystemdError` are added to `guestbus`. Section 2a's consequence for P2 asks for
  errors that keep systemd's class: the D-Bus error name, or "gone" for a closed peer. A type
  carries the name without making callers parse the error text.
- `ErrNoUser` is added: a zero `paths.GuestUser` would panic in `paths.SessionUnit`.
- `unit.ErrInvalid` is added, as the one sentinel for Render's and ExecStart's refusals.
- `Dial` also closes `c` on every failure, and ends with `ctx`.
