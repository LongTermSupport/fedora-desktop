# n2f part "units": systemd over D-Bus (SPEC-n2f section 6, SD1-SD9)

Branch `feat/bus-v2-n2f-units`, commit `78e3633a`.

## What was built

`src-go/internal/teamchat/units`:

- `NewManager(dial func() (Conn, error), r execx.Runner) *Manager`, `SystemBus`, `Host()`
  (`host.Systemd`), `Health()` (`health.Units`), `Close()`. `Conn` is `Call(ctx, dest, path, method, args...) ([]any, error)`, `Signal(ch)`, `Close()`; `busConn` adapts `*dbus.Conn`.
- The connection opens on the first call. Setup adds two match rules (JobRemoved from
  `org.freedesktop.systemd1`, and NameOwnerChanged for that name from the bus), reads the
  name's owner, and calls `Subscribe`. A dispatcher goroutine drains the signals. A non-D-Bus
  call error, or the signal channel closing, drops the connection, and the next call dials
  again (SD7).
- Start, Restart and Stop (SD1) use mode `replace` and wait for the job's JobRemoved. A
  JobRemoved that arrives before the reply is kept while a job call is in flight. `done` is
  success. Any other result is `ErrJobFailed`, naming the verb, the unit and the result (quoted,
  or "an unprintable result"). A context that ends first is its own error.
- Reload (SD2), Enable and Disable followed by Reload (SD3), host State (SD4), health State
  (SD5): each property is type-asserted, InvocationID must be 16 bytes or empty, and
  ActiveEnterTimestamp 0 is the zero time. CleanState and JournalTail run through execx (SD6).
- Error classes (SD7): `ErrNoSuchUnit`, `ErrNotPermitted` (AccessDenied,
  InteractiveAuthorizationRequired), `ErrMasked`, `ErrUnreachable`, `ErrSystemd` (shown by its
  D-Bus name), `ErrMalformed`, and `ErrUnitName` (SD8, checked before any call). A bus string
  is shown only when it is one printable line of at most 256 bytes. Every error is one line.
- Dependency: `github.com/godbus/dbus/v5` v5.2.4, the latest tag, which requires only
  `golang.org/x/sys` (already listed). It is vendored with its allowlist row. The keepout row
  is unchanged and holds. `qa-go-deps` passes.
- `qa-go-vuln` reports one reachable finding, GO-2026-6809 in the stdlib, which is the expected
  one. Its module results list x/text GO-2026-6629 as not called; that finding was already
  there before this branch. There are no findings in godbus.

## Tests and coverage

98.4% (`go test -race -shuffle=on -cover`). The suite passed 20 shuffled runs in a row.
golangci-lint is clean with and without `--build-tags tuwunel`, go vet is clean, and the
project rules pass.

- Fake `Conn`: every method, and the JobRemoved signal arriving both before and after the
  reply (hooks make the order deterministic). Every job result. A forged sender, another job,
  another member, another path and a malformed body are all ignored. An owner change is
  followed, and a peer's claim of an owner change is ignored. Every error class. The context
  ending during the wait and during the call. A dial failure, a lost call and a channel closed
  while waiting or before the reply, each followed by a redial. Setup failures close the
  connection. Unit-name refusal happens before any dial or program. Bad property types.
- Wire test, `TestSystemdOverARealBus`: it starts a scratch `dbus-daemon` through execx from a
  config the test writes, exports a fake `org.freedesktop.systemd1` Manager (godbus `Export`)
  and a unit object (`prop.Export`), and runs the real adapter through `SystemBus`
  (`DBUS_SYSTEM_BUS_ADDRESS`). It then kills the bus, checks the call fails as unreachable, and
  checks the next call dials a second bus. The test skips only when `dbus-daemon` is absent.
  It did not skip in this container.

## Decisions

| ID     | Decision                                                                                                                                                                                                                                                                     |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| n2f-U1 | SD8 accepts only `teamchat-server@<instance>.service` (`paths.Product`), with the instance in systemd's characters `[A-Za-z0-9:_.\-]`, at most 255 bytes.                                                                                                                    |
| n2f-U2 | A JobRemoved counts only when its sender is the current unique owner of `org.freedesktop.systemd1`, read at setup and followed through the bus's NameOwnerChanged. Any peer can send root a unicast signal, so without this check a forged JobRemoved could end a job early. |
| n2f-U3 | Reply values are type-asserted, never passed through `dbus.Store`. Store converts between kinds: a string becomes an object path, a number becomes a string. A test caught this, hanging on a bad job reply.                                                                 |
| n2f-U4 | For SD4 and SD5, "not loaded" means LoadUnit answers NoSuchUnit. That gives `inactive` and not enabled, for health too. A loaded unit's ActiveState is reported as it is, so a unit still running after its file is removed reads `active` and `remove` still stops it.      |
| n2f-U5 | ActiveState, SubState and UnitFileState must each be a lower-case state word (`[a-z][a-z-]{0,63}`); UnitFileState may also be empty. Anything else is `ErrMalformed`.                                                                                                        |
| n2f-U6 | "Printable" (SD7) also refuses non-printable runes, such as terminal escapes, not only newlines.                                                                                                                                                                             |
| n2f-U7 | `qa/rules/table.go` now lists `internal/teamchat/units` as a second owner of `systemctl`, for `clean --what=state` (n2f-D4). `internal/systemd` is v1's and is left untouched.                                                                                               |
| n2f-U8 | `SystemBus` is godbus `ConnectSystemBus`, which has no context. A bus that accepts the connection but never authenticates would block the dial. This was accepted because it is a local socket.                                                                              |
| n2f-U9 | The JournalTail text is returned as journalctl printed it (SD6: it is only shown). It is not sanitised here.                                                                                                                                                                 |
