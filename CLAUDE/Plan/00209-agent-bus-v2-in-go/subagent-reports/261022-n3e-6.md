# n3e-6 report: delivery (DV1's use, DV2, DV3, the session-level send for DV6)

Branch `feat/bus-v2-n3e-6`, base 640af55ed. Three builders: the first wrote the design and the
RED tests (`261022-n3e-6-handoff.md`), the second the engine, the third the link hunk and this
report.

## What was built

- **Engine** (`member/engine`): `deliver.go` (the session's facts, `Live`, `SetSession`,
  `SendMembership`, the trailing facts, the stall, the namer), `deliverloop.go` (the delivery
  loop: pick, refetch, prepare and `deliver.Build`, dial, the awaiting entry, the user line,
  the ledger, finish), `points.go`, `points_armed.go`, `points_inert.go` (the engine's
  failpoints by number), and hunks in `engine.go`, `seam.go`, `recv.go`, `teams.go` and
  `status.go` (awaiting items guarded, the trailing facts kept on persist, the stopped fact
  reset, `Stalled` in the status row).
- **Link** (`member/link`):
  - `build` gives the engine `Inbox: inbox.NewDialer(clock)` in socket mode only (nil for wait
    and plain launches), `Unusable: session.Unusable()` and `OnUnusable: l.onUnusable`.
  - `onUnusable` keeps the latest render count under a mutex and wakes `recordRender`, a
    `l.bg` goroutine. It writes `unusable.render` into session.json through
    `Session.RecordRender`, and writes the last count once more when the link ends. A write
    that fails is logged (`link: record the render count: ...`) and never stops the link.
  - `KindToken` also calls `eng.SetSession` with the socket and transcript session.json
    holds (`Session.Inbox()`) and the token, so a restarted link delivers again before any hook.

## API as built (for n3e-7, n3e-9, n3e-10)

```go
// package engine
type SessionFacts struct {
	Socket, Token, Transcript string // empty keeps the value set before
	Idle                      bool   // always taken
}
func (e *Engine) SetSession(ctx context.Context, f SessionFacts) error // pokes the loop; a Socket clears gone
func (e *Engine) Live() bool // socket mode, Inbox set, socket+token+transcript told, not gone; false once ended
func (e *Engine) SendMembership(ctx context.Context, m proto.Membership) (bool, error) // true only on a full write

// engine.Config gains
Inbox      inbox.Dialer         // nil: no socket delivery
Unusable   state.Unusable       // session.json's counts at the link's start
OnUnusable func(state.Unusable) // on the state goroutine; must not block; nil allowed

// in deliverloop.go
const paceWait, retryWait, stallAfter, trailingEvery = 2*time.Second, 10*time.Second, 120*time.Second, time.Minute

// package link
func (s *Session) Unusable() state.Unusable
func (s *Session) Inbox() engine.SessionFacts // Socket and Transcript from session.json; empty before the first facts
func (s *Session) RecordRender(n int64) error // session.json with unusable.render = n, the rest unchanged
```

For n3e-7 (the hooks): every accepted hook op should call `l.eng.SetSession(ctx, engine.SessionFacts{Socket: f.Socket, Transcript: f.Transcript, Idle: <Stop, or SessionStart with no prompt since>})`. The token is not in the facts; the engine keeps the one the token message
gave. `hook_stdin` is not written by n3e-6: `RecordRender` keeps whatever `s.file` holds, so a
hook-stdin writer must go through the same `Session` mutex.

For n3e-9 (proof): awaiting items stay in `pending` with `handed` set to the nonce (D1). Proven
removes them from pending and removes the entry. Missing sets `handed` nil, sets `repeat` and
`held`, and removes them from the ledger.

## Decisions

- **D1** (accepted by the lead): awaiting items stay in pending, handed to the nonce. They are
  guarded in `settleStore`, `restoreHanded`, `apply`'s redaction (content kept too) and
  `held.pending()`.
- **D2**: `deliver.Item.Question` is nil. The engine has no question index yet.
- **D3**: engine failpoints pass a `point` number, not a `failpoint.Name`. `point.name()` is
  resolved only in `points_armed.go` (busfailpoints) and in tests. A `func(failpoint.Name)`
  field kept the names in the release binary, and `TestAReleaseBuildHoldsNoPointName` failed.
- **D4**: every turn that chose a team consumes a pace slot (a dial, an empty build, a Build
  error, an abandon), measured from the turn's start. A turn that chose nothing consumes none.
  The loop picks before it waits out the pace, so it idles (counted) when nothing is
  deliverable.
- **D5**: Finish runs only after a full write and after its record. A Gone dial is not a stall
  failure.
- **D6** (third builder): the token message's `SetSession` carries `Idle: false`, because a
  restarted link does not know whether the session is idle. False is the engine's initial
  state anyway; the next hook tells the truth.
- **D7** (third builder): `Session.Inbox()` returns an `engine.SessionFacts` instead of two
  strings. The linter forbids named results, and two unnamed strings could be swapped without
  the compiler noticing.
- **D8** (third builder): the render writer is started in `run` beside `reportStates`, not in
  `build`. A build that fails returns before teardown, so a goroutine started there would never
  be waited for. Its final write at `quit` means a count told just before the end is kept.

## Test fixes, each with its reason

- `TestDeliveryOverTheInboxSocket` read `dw.clk` before the world existed. A wrong token is
  also invisible to the link, because the inbox never answers the auth line and Dial succeeds.
  The test now checks that a real delivery is written yes, that a wrong token gets the refused
  frame, and that no token is in link.log.
- `TestNoDeliveryBeforeTheFacts`, `TestAGoneSocketStopsDelivery` and
  `TestAFailedFinishKeepsTheWrite` waited on idle counts that the initial idle or a coalesced
  poke could already satisfy, or that were never reached. They now wait on the condition
  itself, or on one idle after a settled read.
- Lint-only changes: `advance(d)` (n was always 1), `live` returns nothing, `checkPhases` split
  out, field order.
- New link tests (`member/link/deliver_test.go`) have short names, because link.sock's path
  includes the test's temp directory and must fit in 100 bytes.
