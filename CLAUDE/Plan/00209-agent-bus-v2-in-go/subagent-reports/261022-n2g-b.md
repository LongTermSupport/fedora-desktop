## The verbs (BV1-BV4)

- `backup --team T`: `teamlock.Take(..., "backup", BackupWait, sys.Host.Clock, sys.Host.Guard)`,
  `backup.Take(ctx, *sys.Backup, lock, nil)`, then `sys.Host.Status.Refresh(ctx, team, false)`
  whether or not the backup was taken, then the release; all errors are joined. A backup taken
  prints `{"v":1,"team":"T","backup":n,"time_ms":t,"pruned":[...]}`, even when the refresh then
  fails (exit 1), as the member verbs print their bundle.
- `backup --all`: `health.Stamps{Root}.Stamped`, then each team as above in turn. stderr gets
  `<team> backup <n>` or `<team> failed: <error>` (one line each), stdout gets nothing, and the
  exit is 1 if any team failed (n2g-D5). A stamp that cannot be read fails the run before any
  team is backed up.
- `backups --team T`: no lock; `backup.List` and `Listing.Value(team).Compact()`.
- BV4: `--all` with `--team`, neither, a positional, an unknown flag or a bad team is 64, and
  nothing is done. The class gate is `Run`'s: `backup`, `backups`, `restore` and
  `restore --lost`, run as the ctl uid or another uid, are 77 and the System is never built
  (`TestBackupVerbsAreRootsOnly`).
- `TestEveryVerbEveryClass` still holds: a built verb with no System says "not wired yet".

## Decisions

01. Root's own files (team.json, config.toml, the tars, last-run.json, `backups/`) must be owned
    by the running euid (0 on a host), so Deps needs no field for them. teamlock and seat check
    the same way.
02. The sources are read first (step `sources`), before the ready check, so a missing source
    sends no signal. The port and server name come from `team.json`, which matches units.json's
    port at step 6 because step 11 of the same apply writes both.
03. A changed invocation, or a unit not active just before the signal, is `ErrLost` (69). So is
    a unit lost by the 60 s deadline: the state is read again at the timeout. A server not
    running at the first read, or not answering, is `ErrNotRunning` (70).
04. A tar that fails its read-back is removed, so HB1's "both halves" never counts a bad tar.
05. BV3's `time_ms` is the meta's time, else the valid tar's manifest time, else null.
06. The token grammar is copied from ctl's unexported `isToken`. I propose `paths.CtlAdminToken`
    and an exported ctl check at merge.
07. last-run.json's error is made one line: newlines become "; ", other control or format
    characters "?", and the result is cut to 512 bytes, so it passes `status.OneLine`.
08. `System.Backup` is a `*backup.Deps` and not a narrower interface. The verb tests run the real
    engine over the admin world (fake units whose Kill writes Tuwunel's meta file), so the verbs
    are proven against `Take`'s real exits and files, not against a stub.
09. The verb's lock name is `backup`, and `backup --all` runs each team under its own lock in turn,
    so a team that is busy (75) fails only its own line.
10. RT1's pid comes from `/proc`, found by the run's own config path (`Server.Signal`). Matching
    on the binary's name could pick up another test's server.
