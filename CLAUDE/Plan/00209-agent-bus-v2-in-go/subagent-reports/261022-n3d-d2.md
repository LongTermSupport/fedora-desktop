## What was built

- **Login**: runs `gh` with the arguments `auth token --hostname github.com` through
  `execx.Runner` (constant name `gh`; gh is in no owner table, so no `dynamicNames` row was needed
  and the seam rules pass) only when a request is about to go out. The credential is held at most
  10 minutes on the boot clock and dropped at once after a 401. One trailing `\n` is trimmed, and
  the rest must be 1-1024 bytes of `\x21-\x7e`. Each of these is `ErrLogin`: gh not installed, an
  error, an exit other than 0, or a token off the grammar. A context that ends while gh runs gives
  the context's error instead. Concurrent readers share one gh run, because the mutex is held
  across it.
- **Token**: the value sits in an unexported field. `String`, `GoString` and `Format` (every verb)
  print `forge.Token(redacted)`.
- **Checker**: A 9.3's tables.
  - Repository facts by class: listed requires `full_name` equal to the reference's (case-folded)
    and not a fork. Org requires `owner.login` equal to `forge.org` and not a fork. External
    requires public and not a fork. Excluded never proves.
  - Proving branches:
    - Listed with branches: the ping's branch must be listed (and exist); with no branch given,
      any listed branch will do.
    - Listed with no branches, and org: the ping's branch, which must exist (`branches/{b}`), or
      else the default branch.
    - External: the ping's branch when given (it must exist), else the default branch.
  - Commit form: `compare/{base}...{sha}` is `identical` or `behind`.
  - Path form: the commit proof, then `contents/PATH?ref=SHA` is an object with `type: file`.
  - PR form: the head repository is the reference's own; the author association is `OWNER`,
    `MEMBER` or `COLLABORATOR` (not judged for external); `compare/{sha}...{head}` is `identical`
    or `ahead`.
  - Issue form: the issue exists, and `pull_request` is absent or null.
- **HTTP**:
  - Each request ends after 15 s, timed by `clock.AfterFunc`, which cancels the request's context
    (as matrix's per-try deadline does).
  - Responses are capped at 8 MiB (8 MiB + 1 is refused).
  - Redirects are followed only to the same scheme and host, and at most 5. A redirect anywhere
    else is refused before that origin is asked anything.
  - Proxy is nil, as in matrix.
  - Rate path: a 429, or a 403 carrying `Retry-After` or `X-Ratelimit-Remaining: 0`. The wait is
    `Retry-After` in seconds, else `X-Ratelimit-Reset` minus `WallMS`, else 5 s. There are three
    tries. A wait over 60 s is not slept and gives `forge-rate`.
  - Any other 403 is unresolved. A 401 drops the token, reads it again and retries once; a second
    401 is unresolved and drops the token again. A 5xx or a transport failure is `ErrDown`.
- **Health** (n3d-D29): after `ErrDown`, every check is `ErrDown` with no request until
  boot + 60 s; at exactly 60 s it asks again. A check ended by the caller's own context is not
  counted as down.
- **Caches** (n3d-D22): up to 1024 entries each, oldest put evicted first, on the boot clock.
  - Repositories, branches, reachability, pull requests and issues are kept 3600 s (expired at
    3600 s).
  - A file at a SHA is kept for the link's life.
  - Only facts that can prove are cached: a repository that passed its class check, a branch that
    exists, a compare that reached, a file, a pull request whose head repository and author
    passed, an issue that is not a pull request. A check whose facts are all cached runs no
    request and no gh.

## Exported API, exactly as built

```go
const Proven = "proven"
type Result struct{ Outcome string } // Proven | proto.ReasonProvenance | proto.ReasonUnresolved | proto.ReasonForgeRate
var ErrLogin = errors.New("forge: no forge login")
var ErrDown = errors.New("forge: the forge did not answer")

type Token struct{ /* unexported */ }
func (Token) String() string
func (Token) GoString() string
func (Token) Format(f fmt.State, _ rune)

type Login struct{ /* unexported */ }
func NewLogin(r execx.Runner, c clock.Clock) *Login // nil c is clock.System()
func (l *Login) Token(ctx context.Context) (Token, error)
func (l *Login) Drop()

type Config struct{ Login *Login; Clock clock.Clock } // Login required; nil Clock is clock.System()
type Checker struct{ /* unexported */ }
func New(cfg Config) *Checker
func (c *Checker) Check(ctx context.Context, need proto.ForgeCheck, f proto.Forge) (Result, error)
```

`Check`'s error is one of these, each returned with outcome `unresolved`:

- `ErrDown`, wrapped;
- `ErrLogin`, wrapped;
- the context's error, wrapped;
- an error for a forge kind with no origin.

`provenance`, `unresolved` (for not found, wrong kind or a refused credential) and `forge-rate`
come back with a nil error. The origin is `proto.ForgeOrigin(f.Kind)`; tests replace it only
through `export_test.go` (`SetOrigin`).

## For W: lining up with D1's `team` types

D1 was not merged when this was built, so forge defines its own `Result`, `ErrLogin` and `ErrDown`
and does not import `team`. It has no compile-time `team.Forge` assertion yet. When W wires it,
in forge:

- make `Result` an alias: `type Result = team.ForgeResult`;
- set `var ErrLogin = team.ErrForgeLogin` and `var ErrDown = team.ErrForgeDown`;
- add `var _ team.Forge = (*Checker)(nil)`.

`team` does not import forge, so this makes no cycle. The outcome strings already match D1's
(`proven`, `provenance`, `unresolved`, `forge-rate`).

## Go doc facts relied on (section 2c)

- `execx.Fake.Run` returns an `*ExitError` for a non-zero `ExitCode`. Login treats any error or
  non-zero exit as `ErrLogin`, and `execx.IsNotInstalled` as "gh is not installed".
- `clock.Clock` has `Boot`, `WallMS`, `Sleep` and `AfterFunc`. `clock.Fake.Advance` fires
  waiters on the caller's goroutine.
- `proto.ForgeCheck{Ref, Class, Branch, Branches}` and `Trust()`; `proto.RefClass` (Excluded,
  Listed, Org, External); `proto.Forge{Kind, Org, Repos, ...}`; `proto.ForgeOrigin`; the
  `proto.Reason*` constants.

## Decisions (simpler, recorded)

- **External with no ping branch** is proven from the default branch. A 9.3's external row names
  a branch only "when given", so something had to stand for the proving branch otherwise.
- **A given branch is checked with `GET branches/{b}`** before any compare, so a missing branch is
  `provenance` (the reference was found but not proven). Then, if no compare finds the SHA at all
  (404, 410 or 422 on every proving branch), the result is `unresolved` (not found); if one finds
  it but does not reach, `provenance`.
- **Branch names stay one API path.** A name with `..`, an empty component, or a component
  starting with `.` is refused: `provenance` for a ping's branch, skipped for a roster branch.
  ValidBranch allows those characters, but git refuses such names, and without the check the name
  could steer the request to another API path.
- **Wrong kind** (a directory or symlink for `path`, a pull request for `issue`) is `unresolved`,
  as A 9.3 lists "wrong kind" there. So is a 200 answer whose body does not decode, and any status
  other than 200, 404, 410 or 422 after the rate, 401 and 5xx paths.
- **The repository facts cache** keeps an entry only when the class check passed, so a fork or a
  private external repository is asked again every time.
- **The compare cache is keyed on the path and the statuses accepted**, so a commit compare and a
  PR compare that happen to share a path cannot collide.
- **Proxy is nil**, as in matrix: the forge is reached directly.
- **`Config.Login` is required.** No guard was added for a nil Login; W always passes one.
