# Plan 00209 — Journal 26-10-23

_Scaffolded by `mkplan.bash`; timestamps in this file are UTC._

> **Append-only activity log** for plan 00209. One file per day
> (`00209-Journal-YY-MM-DD.md`). `PLAN.md` tracks the plan (what/why,
> current state, tasks); this journal tracks what actually *happened* —
> findings, decisions, dead-ends, hand-off state — the linear lifecycle a plan
> document structurally cannot carry.
>
> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier
> entries (corrections are new entries):
>
> ```
> ## HH:MM · category · REF   — optional short title
> ```
>
> - `HH:MM` UTC 24h (the date is in the filename, also UTC); times increase
>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).
> - `category` ∈ `action` | `finding` | `decision` | `thought` | `blocker` | `handoff`
> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

## 06:30 · decision · —

n3e-10 merged into n3e (b2bafaa9c), with n3e-watchleak's fix.

QA on the merge found leakcheck reporting proof.(*watcher).run. It was a test fault, not a leak: one test registered leakcheck.Check twice, and the later check judged while the other world still ran. Rule project_leakcheck_once found 6 instances in 5 tests, matching the independent search, and all are fixed.

Deviation from Defence Before Fix: the rule's red was proved in the work tree, not in a commit. The merge resolution and the fix were staged together, and the merged tests do not compile against the pre-merge engine, so a red commit could not sit between them. The rule's analysistest fixture holds red and green.

Lesson for the lead: before a fixer works in a staged merge, commit the merge, or have the fixer work on a branch from the merge commit, so the red commit has a place.
