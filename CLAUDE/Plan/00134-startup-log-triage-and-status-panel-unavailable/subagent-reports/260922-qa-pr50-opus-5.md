### 4. The desktop half of the same defect is still live — real gap, in scope

`playbooks/imports/play-basic-configs.yml:483` (branch line numbering)

A desktop-profile host whose image lacks abrt — minimal/netinstall plus GNOME, a spin

`CLAUDE.md`, *Missing Dependencies — Fail Fast, Fix in IaC*: the fix for a tool the

**Fix (one line)**: add `abrt-cli` (plus `abrt-desktop` if the applet is wanted) to
the `packages` list at `playbooks/imports/play-basic-configs.yml:80-88`, or as a

This is the "lesson written down beside the thing it fixed, never generalised" shape
from `CLAUDE/AgentNotes.md`: the fix covers the population the author hit, not the
population the defect has.

### 5. The gate leaves state behind, against the convention stated 370 lines above it

`playbooks/imports/play-basic-configs.yml:91-101` and `:102-108`

The play argues its own convention explicitly:

> the server profile REMOVES this play's block rather than merely not writing it: a
> box provisioned as a desktop and later rebuilt as a server ends up in the state its
> current profile declares, and nothing downstream has to undo what this play did.

and implements it at `:107` with
`state: "{{ 'absent' if provisioning_profile == 'server' else 'present' }}"`.

The new ABRT block does the opposite. On a host provisioned as desktop and later
detected as server:

- the `# ANSIBLE MANAGED: ABRT crash policy` block stays in `localhost.yml`;
- `/etc/systemd/system/abrt-prune-stale.{service,timer}` stay deployed;
- `abrt-prune-stale.timer` stays enabled and fires daily.

Its `ExecStart` runs `files/usr/local/bin/abrt-prune-stale.bash`, which calls
`abrt-cli` at line 32 under `set -euo pipefail` — so the unit **fails every day** on a
box with no abrt. The docs claim "nothing is persisted to `localhost.yml` for it" is
false for that host.

Note the flip is not purely hypothetical: `environment/localhost/group_vars/desktop.yml`
resolves a `systemctl get-default` **failure** to `server`, so a transient detection
failure on a real desktop puts it on the server branch for that run.

**Fix**: converge the removal the way `:107` does, or state the limitation in the docs.
