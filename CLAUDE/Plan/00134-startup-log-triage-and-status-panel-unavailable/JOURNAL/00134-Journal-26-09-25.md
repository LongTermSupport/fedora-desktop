## 12:02 · finding · T3.1   — the Permissive relabel stops ccy in a project with a root-owned entry

The owner reported that ccy would not start in one project (project A). Before the
container ran, podman printed `Error: lsetxattr(label=system_u:object_r:container_file_t:s0)
<project A>/…/triage-runs/<timestamp>: operation not permitted`, and ccy exited 126.

Cause, from the code and podman's error. CCY 3.65.0 (this task) makes a Permissive host
bind the workspace with `:z`, and Plan 00139's deploy delivered it. Rootless podman
relabels every entry under a `:z` bind from inside its user namespace, where it holds
CAP_FOWNER only over the uids the namespace maps: the owner's and their subordinate range.
So an entry owned by any other uid fails with EPERM, and the container does not start.
The entry named is a triage-run directory from August. Its owner has not been read on the
host yet; root, from a run under `sudo`, is the likely one. Before 3.65.0 this host bound
the workspace without `:z`, so the entry was never touched.

## 12:02 · decision · T3.1   — explain, print the commands, offer the fix (y/N)

Owner's choice: explain the problem, print the exact commands, and offer to run the fix
after a y/N confirmation. Declining leaves everything as it was.

Built test-first in CCY 3.68.0 (`scripts/test-ccy-relabel-preflight.bash`, 36 cases; red
before the code). Before the workspace mount is built, `workspace_relabel_preflight`
reads the uid map through `podman unshare`. It then finds entries owned outside that map,
and prints each entry, its owner, a `find` that lists them and a `sudo find … -exec chown -h`
that gives them to the owner. The fix runs on `y`, and the entries are checked again
afterwards. The launch stops on `n`, on Enter, on three answers that are neither, or when
there is no terminal. A foreign entry that already carries the shared label, in a project
whose top carries it too, is left alone. This mirrors the relabel walk's skip of entries
that already carry the label, as read from go-selinux's `Chcon`. That skip has not been
measured on the host.
