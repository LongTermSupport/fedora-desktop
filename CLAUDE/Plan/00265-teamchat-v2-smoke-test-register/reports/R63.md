## Defence Before Fix

The class is a converge-time verb that fails on a state the converge legitimately meets. A
`go/analysis` rule cannot express it. Whether a state is legitimate for a converge is a fact
about the verb's contract with its callers (here, a play that runs `declare` on every
converge while the owner may have the session open). No syntax tree carries that fact. A
heuristic such as "an error return after a liveness check" would flag every correct refusal
too: `forget` must refuse while live, and so must the stopped-record refusal here. So the
tests are the guard: each state a converge meets (same record, different record live or
stopped, no record live, with and without `--replace`) has its exit code and stdout pinned.
