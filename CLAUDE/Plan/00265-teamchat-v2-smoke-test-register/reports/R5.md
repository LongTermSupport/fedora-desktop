## R5: a bare `--teams <team>` with no free seat adds one

`chooser.Teamchat.NewSeat` existed but `app.go` never set it, so the "no free seat" outcome said
`ccy-teams seats add <team>` and exited 78.

- `seatadd.Adder.NewSeat(getwd, say)` is the chooser's `NewSeatFunc`: it parses the team, takes
  the working directory as the checkout (the same `os.Getwd` system.Cmd keys the pool by), runs
  `Adder.Add` with `Host` for a host launch, and answers `<N>@<team>`. Progress (the adder's
  notes) and refusals go through `say`, wired to stderr; stdout stays the launcher's payload.
  Exit codes: a bad team 64, a team with no status record on this machine (served elsewhere) 78
  with the adder's message naming the `member add | place-issued` route, anything else 1.
- `app.go` builds one `seatadd.Adder` and uses it for both `ccy-teams seats add` and the
  chooser's `NewSeat`.
- The chooser says `Adding a new <kind> seat of <team> to this checkout (ccy-teams seats add <team> [--host]).` before the add. The add runs only on an attended launch (an unattended one
  goes to `unattendedWays`), so sudo's password prompt has a terminal.
- `ccy` (podman) and `cc` (host) both reach it through `ccy-teams choose-teams --type=<kind>`;
  the adder issues through password sudo on this machine, which works for both kinds. Off the
  homeserver's machine it is refused (78) as before, with the cross-machine route named.

## R55: a seat chosen without checking its kind (Defence Before Fix)

**Class:** a pool seat picked (offered, counted, defaulted, or matched by seat part) without
checking its kind (the handle's type: `podman` for ccy, `host` for cc). **Hazard:** an agent
starts under another launcher's identity, or a launch is told it has seats it cannot use.

**Detector:** no analyzer can tell a kind-blind pick from a legitimate kind-blind read (the seat
sweep, shutdown and `freeHandle`, which must see every seat), so the defence is the type
system: every pool reader a launch chooses from now takes the kind as a parameter, and the
compiler refused every caller until each named one. Changed signatures:
`system.PoolState(..., kind)`, `system.Cmd.SeatCount/Handles/PoolState(team, kind)`, the
chooser's `Teamchat.SeatCount/Handles/Pool(team, kind)`,
`teamchatlaunch.ChooseSeat(pool, team, seat, kind)` and the required `Launch.Kind`.

**Sweep (every instance fixed):**

| Place                                             | Was                                        | Now                                                                  |
| ------------------------------------------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| chooser `teamchatSeat`                            | every pool seat offered and defaulted      | the launch's kind only; none, then `NewSeat`                         |
| chooser `unattendedWays` / `waysOn`               | every seat named, launcher from memberType | the kind's seats, `seatchoice.WaysOn(kind, ...)`                     |
| chooser list (`withTeamchat`)                     | count of every seat; 0 meant agent-bus     | the kind's count; `entry.teamchat` marks a teamchat team at 0        |
| chooser `poolHandle` (a named seat, host)         | matched by seat part in every seat         | the kind's; the other kind's is refused by `seatchoice.WrongKind`    |
| `teamchatlaunch.ChooseSeat` (launch-args, cc-run) | matched by seat part in every seat         | the launch's kind; the other's refused (64) naming kind and launcher |
| `HotSeats.Choose` (a running session's join)      | named or lowest free of every seat         | podman only (a cc session on teamchat is not changed while it runs)  |
| `seatchoice.AddCommand` / `NewRow` / `WaysOn`     | always `ccy-teams seats add <team>`        | `--host` for a host launch, and the launcher named from the kind     |

Kind-blind reads left on purpose: `seatadd.freeHandle` (a seat number is unique across kinds,
since a launch chose by seat part), `seatsweep`, `shutdown/v2host`, `system.PoolTeams` (a team
is on teamchat in this checkout whatever kind its seats are).

Left as found: `internal seat-check` names `ccy` in its ways on for a list-grammar refusal even
when cc runs it (cc does not pass `--type` to seat-check); minor, not a pick.
