## Notes

- C.4 says the seat unit reads the root-written `/run` env file, "that file is then 0600". The first half holds. The 0600 is a requirement of the design: `restart.go` writes the file 0o644 today, so C.4 must change the mode. The plan words it as a result of the design, so it is not refuted.
- The PLAN.md "Open, unchecked" row (whether Fedora's `lxc` ships `lxc@.service`) is honestly marked unchecked. Nothing in the repo settles it, and `boot.go:162` only assumes it.
