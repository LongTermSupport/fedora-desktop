## Decisions

- **Finding 5:** I extended the digest rather than refusing. The build context's other files
  stay unhashed: they are the project source, which a session edits by design, and the image's
  host reach is fixed by the approved compose text. Any path interpolated from a variable other
  than `${PWD}` is refused.
- **Finding 4:** the approval holds no device or inode. An rclone FUSE mount gets a new device
  number per mount, so every restore after a reboot would refuse it. With container-writable
  trees refused, the resolved real path is enough.
  - **Every existing mounts approval must be approved again** before the checkout's next
    unattended restore.
  - `~/.config/rclone` is now denied (cloud credentials). It was allowed before, and a test
    pinned that.
- **Findings 11, 9 and 4 have no detector.** No analyzer can tell these classes apart from
  correct code, so each was closed in its one function.
