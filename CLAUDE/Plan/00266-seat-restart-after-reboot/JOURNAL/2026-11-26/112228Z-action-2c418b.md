## 11:22 · action · — — C.2: absent forgets the seat; boot unit blocked on lxc-start namespace

`lxc apply --phase absent` now takes each leaving seat out of the started record first, as `lxc stop --member` does. The tests were red before the change and green after.

The boot unit is built in the working tree but not committed. The v1names gate requires `InaccessiblePaths=` on every installed service. A container that `lxc-start` starts from such a unit inherits that mount namespace, so the container start has to go through `lxc@<name>.service`. The proposed fix and the state of the work are in `subagent-reports/261126-c2-unit.md`.
