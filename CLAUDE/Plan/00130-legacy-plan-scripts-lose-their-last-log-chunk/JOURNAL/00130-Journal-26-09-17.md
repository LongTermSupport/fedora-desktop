## 14:05 · action · T2.2 — one of the seven is discharged, and it was dead before it ran

`00079/unit-test-selection.bash` is the one script in the owed set that runs anywhere —
its header says so, and the reason is that it drives podfreeze's selection functions
against a synthetic inventory and needs no podman. Run in the container it exited 1
immediately:

```
podfreeze: the shared freeze library is missing.
  Expected at ~/.local/lib/freeze/freeze-common.bash
```

**It is not a missing dependency, and the repo is not short a file.** `podfreeze` grew a
shared library — the one `lxcfreeze` also uses — resolved relative to `${BASH_SOURCE[0]}`
and sourced at line ~163, *above* this test's cut marker at line 795. The test cuts the
tool into a flat `mktemp` file and sources that, so `${BASH_SOURCE[0]}` is the temp path
and the resolver looked for `/lib/freeze/freeze-common.bash`. It calls `exit 1` before a
single function is defined. The repo's copy at
`files/home/.local/lib/freeze/freeze-common.bash` was there the whole time.

I read this as an IaC gap first — "deploy it with play-podfreeze.yml" is what the error
says — and was wrong. The error is accurate about the symptom and misleading about the
cause, because it cannot know it is being sourced from somewhere else.

So this test had been **dead since that refactor**, and nothing could have said so: it is
not in `tests/`, no gate executes plan scripts, and `shellcheck` sees a file that parses.
That is this plan's thesis, found in the wild rather than argued.

Fixed by giving the cut copy the tool's own shape rather than patching the tool: a temp
directory with `bin/` holding the cut and `lib/freeze/` symlinking the repo's real library,
so the real resolver runs unmodified and the test still executes the changed bytes — the
principle the cut exists for. A stub library would have drifted.

Result: `VERDICT: PASS`, exit 0, and the run log ends on its own last line at 5,959 bytes,
byte-identical to the terminal. Both halves measured, on a converted script. `qa-all.bash`
green, 1,001 files.
