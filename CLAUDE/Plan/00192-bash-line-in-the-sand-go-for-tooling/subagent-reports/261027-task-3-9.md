# Task 3.9: qa-changed chooses a suite that reaches a changed file by glob or directory

Branch `fix/00192-qa-changed-glob-suites`, from F44 `fe894347c`.

## The defect class

qa-changed chose a suite for a changed file only when the suite's text named the file (its
path as a substring, its basename as a token), or built from it (Go closure). A suite that
reaches files through a glob (`cp "$REPO_ROOT"/helpers/self_update/*.py`) or a whole directory
(`cp -r "$REPO_ROOT/helpers"`, `ln -s "$REPO_ROOT/helpers" …`, `cp -R "$HOOK_DIR" …`) names
none of them, so a change under it chose no suite.

## The change

`src-go/qa/changed/reach.go`, called from `selectSuites` (now through `namedOrReached` in
`suites.go`):

- **Rooted variables.** Each top-level assignment of a form the suites use is read in order:
  the suite's own directory (`dirname "${BASH_SOURCE[0]}"` / `"$0"`), `cd "<p>" && pwd [-P]`,
  `$(dirname "<p>")`, and `$VAR/<path>` of a variable already rooted. An indented assignment is
  ignored. A top-level assignment to anything else unroots the name.
- **Reaches.** A rooted variable followed by a literal path, joined and cleaned
  (`"$SCRIPT_DIR"/../x` resolves), with quotes dropped. The path stops at the first non-path
  character, so `$ROOT/x/$name` reaches `x`. A bare `"$VAR"` counts only on a tree-command line
  (`cp -r/-R/-a`, `rsync`, `tar`, `ln -s`, `find`, `grep -r`). These are not reaches: an escaped
  `\$VAR` (text being grepped for), a comment line, a definition, the repository root, a path
  that leaves the repository, and anything under `src-go/`, which already goes by build closure
  (otherwise every `cd "$REPO_ROOT/src-go" && go build` suite would run for every Go change).
- **Match.** `path.Match` against the file or any directory that holds it. The reason printed
  is `reaches F through P`, and the file counts as covered. Names are checked first and are
  unchanged, so the change can only add selections.
