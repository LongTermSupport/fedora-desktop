## Deliberate deviation — needs a ruling

`deploy.bash`, `acceptance.bash` and `unit-test-selection.bash` run under `set -uo pipefail`
— **no errexit**, by design: their assertions record PASS/FAIL and continue. The canonical R1
block assumes `-e`, and under these scripts' `set` line a failing `plan_init` /
`plan_require_host` / `plan_start_log` would **return 1 and flow straight on**.

I did not flip them to `set -euo pipefail`: silently changing the error semantics of a
730-line host gate I cannot execute is exactly the class of change that produces a wrong
verdict. Instead each library call is gated with an explicit `|| exit 1`, annotated
`# STANDARD-EXCEPTION(R1): …` as PlanScriptStandards.md provides for.

`triage.bash` already had `-e`, so its bootstrap is verbatim with no guards.

Second judgement call: `acceptance.bash` creates and removes a throwaway container, but
declares `plan_mode gather`, not `deploy`. It invokes no ansible and no legs, so mode affects
nothing mechanically, and `gather` matches its R9 role. If it should be gated, switching it to
`deploy` + `plan_gate_change` is a two-line change.
