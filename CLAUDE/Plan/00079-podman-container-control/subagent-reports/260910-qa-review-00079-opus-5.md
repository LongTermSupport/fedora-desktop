## Should fix

### 1. The anti-regression test for finding 1 does not exercise the production path

`CLAUDE/Plan/00079-podman-container-control/unit-test-selection.bash:265-280` vs
`files/home/.local/bin/podfreeze:728-737`

The axis-offer decision has exactly one site. `grep -n "ccy_total"` on the tool returns
three lines, all inside `pick_target`. The unit test never calls `pick_target`,
`drill_into_group`, `interactive_loop`, `select_network` or `do_action` — a grep for all
five returns nothing. The four new assertions instead re-implement both candidate
predicates inline and assert that the old one is wrong and the new one is right:

```bash
is "  ... so cardinality alone would wrongly suppress the row" \
    "$([ "$(identity_values github | wc -l)" -lt 2 ] && echo suppressed || echo offered)" \
    "suppressed"
```

Reverting `podfreeze:734-735` to `[ "${#values[@]}" -lt 2 ]` leaves all 49 assertions
green. The fix commit message and the journal both claim "regressions that fail on F21
and F22 specifically". That is true for F22, whose test does call
`unlabelled_ccy_names`, and false for F21.

**Fix**: extract the predicate into a named function, e.g.
`identity_axis_discriminates <axis>`, called by both `pick_target` and the test.
`pick_target` itself is untestable as written because it dies without a TTY, which is
why it was skipped.

### 2. The user documentation still describes the rule finding 1 removed

the fix commit `755a6089` changed the code without touching `docs/playbooks.md`.

### 6. A deployed binary is removed by hand rather than by Ansible

`CLAUDE/Plan/00079-podman-container-control/deploy.bash:152-163`

`rm -f "$HOME/.local/bin/podman-freeze"` is a manual system change, which the IaC HARD
RULE prohibits without qualification. The comment argues it is transient and belongs in
the plan folder rather than as a permanent `state: absent` task. The counter-argument:
`play-podfreeze.yml` is directly runnable without `deploy.bash`, and the plan folder
leaves with the plan when it moves to `Completed/`, so the migration disappears while
any un-migrated machine keeps both binaries. A five-line
`ansible.builtin.file: state: absent` task in the play is the IaC-correct home.
Flagged rather than decided: the author's reasoning is on record and the user may
accept it.
