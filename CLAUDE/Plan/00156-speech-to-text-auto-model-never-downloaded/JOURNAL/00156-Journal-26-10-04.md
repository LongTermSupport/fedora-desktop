## 20:16 · decision · T1.1   — searches in; rule host, scope and calibration

The three independent searches are back. The reports are `dbf/search-*.md`, all written
before any rule existed.

- **model present without weights:** 2 confident instances (`prefs.js` `_isModelInstalled`,
  `wsi-model-manager` `get_installed`) and 2 unsure (`_download_done`, `_poll_progress`).
- **dropdown label carries explanation:** 11 instances, all in `prefs.js`.
- **ready-wait ignores child exit:** 16 instances, across Python, Bash, JS, Ansible, tests
  and plan scripts. This class is far wider than the other two, so it becomes its own
  phase. Its original instance (the uncommitted `wsi-stream` fix) stays uncommitted until
  that class's defence has been committed red.

Decisions:

- Plan 00156 stays separate from Plan 00148. The dedupe scout called it a subset, because
  `auto` = distil-large-v3.5 came from 00148 Task 7.4. This plan is a regression fix with
  DBF records of its own, and 00148 is a long-running feature plan.
- The rules live in `.semgrep/speech-to-text.yml`, run by a new hard gate,
  `qa-speech-to-text-rules.bash`, in the project's existing Semgrep host.
- `model-present-without-weights` was narrowed once, to `snapshots` after a quote or a
  slash. The bare word matched `helpers/containerwatch`, where "snapshots" are two
  `/proc` stat readings: no cache, no model, so that code cannot carry the hazard.
- The `dropdown-label-carries-explanation` length limit is 25. The longest short name is
  19 characters and the shortest truncated label is 34. That is a calibration recorded
  as the project's decision, since the project had none.
- The gate's first draft dropped every extensionless script under
  `files/home/.local/bin/`, because a `*.*` case on the whole path matched the `.local`
  directory. Caught by comparing the gate's scanned count with an independent
  `git ls-files` count (206 `.py` + 8 extensionless + 19 JS = 233). The extension is now
  read from the basename.
