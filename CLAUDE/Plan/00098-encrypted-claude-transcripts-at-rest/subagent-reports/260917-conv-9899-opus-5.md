## `00098-encrypted-claude-transcripts-at-rest/triage.bash`

- Same bootstrap replacement; `plan_mode gather`; `plan_start_log auto`; ends with
  `plan_finish`. Header comment updated from "Writes its report to `<plan folder>/logs/…`" to
  the `untracked/plan-runs/` location.
- **`$LOG`-family consumers found and removed: 4** — the `REPORTS_DIR` / `LOG` definitions;
  the final `echo " Full report saved to: $LOG"` (replaced by `plan_finish`); and two
  `PLAN_DIR` uses at the CCY-store fallback (`"$PLAN_DIR/../../../.claude/ccy"`, a
  fixed-depth hop R1 forbids) now `"$REPO_ROOT/.claude/ccy"`. The `git rev-parse` line was
  deleted.
- **Worth flagging.** Adding `plan_finish` made `shellcheck -x` fail with **69 SC2317s**.
  Because the script no longer falls off its end, every function body invoked indirectly
  through `probe "label" fn "$arg"` became "unreachable" — and suppressions are banned (R11).
  This is precisely the trap 00099's `probe`/`emit_probe` comment documents, so the same fix
  was applied: `probe` now delegates rendering to a new `emit_probe`, and the four
  function-backed probes (`posture_census`, `size_and_age_census`, `secret_census`,
  `umask_census`) call their function directly and hand the captured rc/output to
  `emit_probe`. The external-command probes (`ls`, `umask`) still go through `probe`. No
  assertion weakened, no output shape changed.
- `bash -n` OK, `shellcheck -x` clean, mode `0755`.
- **Run**: completed fully in the container, exit 0, `==> all legs OK`. It reported the CCY
  store census, the scanner self-test passing, and `CACHEDIR.TAG present? (rc=2)` as a fact
  rather than a failure — as intended for a fact-finder.
