  normalised with paths, quoted text, ids and numbers folded). Raw ccy-sessions output stays in
  raw-\*.txt in the run directory.

supervisor's `idle` is keyboard idle (no stdin byte for 2 s), not "no turn running"; it ticks
every 2 s; plugins are asked when no built-in family claimed the tick and `can_inject` holds
(keyboard idle, empty input box, main focus confirmed). Pending bus items live in the container's
PINGBUS_HOME (`/tmp/pingbus-home` in the container this was written in), which the supervisor does
not read. The lifecycle plugin's on_idle writes nothing per call.
