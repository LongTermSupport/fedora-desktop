## 11:44 · decision · T1.2   — the one-key agent lives as long as the launcher

The filter is a child of the launcher, and lives exactly as long as the launcher does.

How the launcher runs the container, read from `files/var/local/claude-yolo/claude-yolo`:
every launch runs `container_cmd run ... --rm` in the FOREGROUND of the launcher process
(`DOCKER_FLAGS` is only `-i` or `-it`; there is no `-d`). A "detached" session is a tmux
session whose pane runs that same launcher, so detaching leaves the launcher running. A
restore (`ccy-sessions` after a reboot) starts a NEW launcher in a new tmux pane, which makes
its own decisions from the saved key file. A supervisor restart `exec`s the launcher in place
(same pid), after calling `cleanup` with the EXIT trap removed.

So:

- Started by `ccy_agent_filter_start` (lib/ssh-handling.bash) in the background of the
  launcher, after the early EXIT trap is set and before `build_ssh_mounts_and_validate`
  probes GitHub through it. It listens in a fresh `mktemp -d` directory on
  `XDG_RUNTIME_DIR` (0700), its socket 0600, and is mounted at `/run/ccy/ssh-agent`.
- Stopped by `ccy_agent_filter_stop`: from the early EXIT trap (a launcher killed before the
  container), from `cleanup` (the normal end, a refusal, and the restart path, which runs
  `cleanup` before `exec`), so a restart's relaunch starts its own filter.
- Backstop: `--parent-pid $$`. The filter polls the launcher's pid each second and stops
  when it is gone, so a SIGKILLed launcher (no trap runs) leaves no filter behind serving the
  owner's key. A container that outlives a SIGKILLed launcher loses its agent; that session
  has lost its launcher anyway.

Rejected: a systemd user unit per session (a second lifetime to keep in step with tmux and
restores, and ccy has no unit today for a foreground launch); a filter per container keyed on
the container's own exit (needs a watcher that outlives the launcher, the problem the
parent-pid check removes).

Deployment: the helper is `helpers/ssh_agent_filter/ssh_agent_filter.py`, stdlib only, run
by path. `play-claude-yolo.yml`'s existing "Install Shared Helper Libraries" loop copies it
beside the launcher's libraries, to `/var/local/claude-yolo/lib/ssh_agent_filter.py`; the
library finds it beside itself. No new play.
