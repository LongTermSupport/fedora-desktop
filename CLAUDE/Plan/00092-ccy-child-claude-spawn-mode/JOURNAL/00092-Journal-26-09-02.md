## 08:40 · finding · T1.2 — the self-test found two defects in its first run

`selftest-probes.bash` plants a real violation per invariant and requires the probe
to go red. Its first run failed twice, and both were genuine:

1. **The I1 probe reported a failed search as a clean pass.** Written as
   `if hits="$(grep ...)"`, grep's exit 2 (search error) fell into the same branch
   as exit 1 (no match). `/run` holds the Wayland socket, grep exits 2 on it, and
   the probe said "the token is in none of them". Exactly the "a control silently
   becomes a no-op" failure PlanScriptStandards was written about. Fixed by
   distinguishing all three statuses and enumerating regular files rather than
   recursing. Measured: neither `--devices=skip` nor `-D skip` suppresses the
   socket error during recursion.

2. **The I2 negative case planted no violation at all.** `bash -c 'sleep 30' bash
   <token>` gets optimised into a bare `exec sleep 30`, so the extra argument
   vanishes and the process command line is just `sleep 30`. The probe was correct
   and the test was wrong. Measured both forms; `bash -c 'sleep 30; :'` keeps the
   argument. The trailing `; :` is now load-bearing and commented as such.

Neither would have been found by reading the code, and the I1 defect would have
shipped a gate that passes on a search it never performed.

## 08:55 · blocker · T1.3 — a real token leak, caused by this session

While tracing the I1 probe I ran `bash -x` over a code path that pipes the token
into grep. The trace printed the token value, that output was quoted back into the
conversation, and Claude Code wrote the conversation to
`/workspace/.claude/ccy/projects/-workspace/<session>.jsonl` — which is inside the
HOST MOUNT. The I1 probe now correctly reports that file as holding the token.

This is threat T1 in `SECURITY-MODEL.md` happening for real, before the feature it
guards was even built, and it is the strongest evidence available that the
invariant is worth enforcing.

Copies removed: the `/tmp` trace files. NOT removed: the live session transcript,
which is this conversation's own record and is not mine to rewrite.

**Remedy is the owner's call and cannot be done from here: rotate the CCY OAuth
token.** Until then `acceptance.bash` will correctly report I1 red in this
container, and that red is a true finding rather than a broken probe.

**Standing rule taken from this: never run `bash -x`, `set -x` or any tracing over
a code path that handles the token.** The probes are written so the value is never
printed; a shell trace defeats that from outside the script.
