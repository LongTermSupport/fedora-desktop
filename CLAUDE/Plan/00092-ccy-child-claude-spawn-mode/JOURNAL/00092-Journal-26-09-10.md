## 14:44 · finding · the binary blind spot, measured rather than argued

Before changing anything, the mechanism was reproduced on a two-file fixture in `/tmp`:
one plain text file and one with NUL bytes, both containing the same needle.

```
--- without-match ---   bintest/plain.txt
--- text ---            bintest/bin.dat   bintest/plain.txt
```

`grep` here is ugrep 7.8.4, not GNU grep. Under `--binary-files=without-match` the needle
in the binary file is invisible; under `--binary-files=text` it is found. So the review's
claim is exactly right, and the fix is the right one, on this implementation.

Changed `probe-invariant.bash` to `--binary-files=text` and made the pass line a
`COVERAGE:` statement that names both the searched count and the enumerated count, so a
future change that reintroduces skipping has to either move the number or leave a visible
contradiction. `-l` means only file NAMES are ever printed, so no binary bytes can reach a
log.

Run in this container after the change:

```
COVERAGE: searched 85054 of 85054 enumerated regular file(s) under 7 path(s), 0 skipped
the token is in none of them          exit 0
```

Against the review's measurement of 31,914 skipped out of 84,222, that is the blind spot
closed. Recorded as Decision 4.
