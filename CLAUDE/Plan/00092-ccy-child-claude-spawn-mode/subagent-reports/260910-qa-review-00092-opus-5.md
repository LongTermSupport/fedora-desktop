## Fix before merge

### 1. I1 reports 38% of its file count as searched when it never looked

`probe-invariant.bash:132` passes `--binary-files=without-match`, so binary
files are assumed not to match and are never searched. Line 148 then prints the
**full enumeration count** as coverage. Measured by the reviewer: 84,222 regular
readable files under `/root` and `/workspace` with `.git` pruned, of which
31,914 are classified binary and skipped. The shipped probe run unmodified
printed `searched 85026 regular file(s) … the token is in none of them`, exit 0.

This is the "partial result read as a complete one" class landing on the
invariant that guards the plan's own top-ranked threat. The previous review
round caught I1 at 42% coverage and did not spot the narrowing inside `grep`.

**Fix**: `--binary-files=text`, safe because `-l` prints only filenames.
Otherwise count the exclusions and print
`COVERAGE: n of m searched, k skipped as binary`.

## Verification by the filing session

Finding 1 is **confirmed at the source and demonstrated**, and it is worse than
stated in one respect.

`probe-invariant.bash:132` does pass `--binary-files=without-match`, and line 148
does print `${#files[@]}` — the enumeration count, not a searched count. So the
two facts the finding rests on are exact.

The demonstration, with a token planted in a file containing a NUL byte:

| `grep` mode                    | Token found? |
| ------------------------------ | ------------ |
| default                        | no           |
| `--binary-files=binary`        | yes          |
| `--binary-files=without-match` | no           |
| `--binary-files=text`          | **yes**      |

**The extra hazard: `grep` in the CCY container is `ugrep` 7.8.4, not GNU grep.**
The review's claim that a planted token "matches under default grep" holds for
GNU grep, whose default *is* `--binary-files=binary`; under ugrep the default
misses it, as the table shows. So this probe's coverage depends on which `grep`
implementation is on `PATH`, and the container and the host may not agree.

That strengthens the recommended fix rather than weakening it:
`--binary-files=text` is the only mode that matched under **both**
implementations, so it removes the dependence as well as the blind spot. Any
`COVERAGE:` line added alongside should be counted from what was actually
searched, not from the enumeration.
