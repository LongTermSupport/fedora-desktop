password. I traced today's path. The timer runs the entry point and `cycle.py` as root. For each
play, `RealHost.run_play` puts the root-only become and vault files on pipes owned by the user,
then runs `runuser -u USER -- env -i ... run.bash --headless <play>`, and `run.bash` hands the
password to `ansible-playbook --become-password-file -`. So the plays run as the login user, and
`run.bash` refuses root.

`become: false`. As root, its podman image build, its Go builds and its user-scope `systemctl`
tasks would act on root, not the user, and the ledger would record into root's home. D5 records
that the plays cannot run as root for exactly this reason. No code was changed. Phase 6 was added
with the owner's choice (F-full or G) as Task 6.1. Report:
subagent-reports/261111-option-f-run-as-root-opus.md.
