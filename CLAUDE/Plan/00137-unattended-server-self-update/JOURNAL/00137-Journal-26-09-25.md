## 12:47 · finding · —   — the cycle test failed wherever the checkout is under the home

CI on F44 failed `self-update-cycle` on one check: "searches for no code under the user's
home". The fake ansible found the fixture clone's search paths under `HOME`. The fixture
built its scratch tree inside the checkout. On a CI runner the checkout is
`/home/runner/work/…`, and on a desktop it is under `~/`, so that tree was under the home. The
real clone, `/var/lib/fedora-desktop/deploy`, never is. The test passed only in the ccy
container, whose checkout is `/workspace` and whose home is `/root`.

The scratch tree now lives in the system temp directory, and the test refuses to run if
even that is under the home. Reproduced from a checkout under `/root`: the old test fails
that one check (162 of 163), and the new one passes 163 of 163. The code under test did not
change.
