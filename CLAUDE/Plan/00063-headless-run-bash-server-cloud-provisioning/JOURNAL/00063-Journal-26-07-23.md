## 09:10 · finding · T1.5b — empty-GitHub HTTPS path gotcha (self-found while auditors deliver r3)

`run.bash:1159` uses hardcoded SSH url (`:1156`); pulls at `:1175`/`:1508`. **Trap

the migration on GitHub-enabled). Pull at `:1508` is read-only over HTTPS public —
fine. `curl https://github.com` reachability wait at `:180` is unaffected.
