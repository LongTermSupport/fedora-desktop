`:2284` is the real call, and `grep -n with-token` finds no other. The uncomfortable part:
**yesterday's journal already says so.** `00063-Journal-26-09-15.md:152` records
`run.bash:2254` as *"drifted — now a scope-satisfier `case` arm; the PAT-on-stdin call is

document anyone actually reads. That is the Plan Commit Rule's failure mode exactly: plan
state lagging the work that was already done.

do with secrets, finds no pipe, and has to decide whether the plan is wrong or they are.
