## 10:18 · finding · —   — the admin's joined rooms hold Tuwunel's version-11 admin room

Task 2.7: the host's play-agent-bus.yml stopped with rc 70 on every team at "list the admin's
rooms: the homeserver answered with no list of room IDs". The host probe found each admin in two
rooms: the team room (version 12) and Tuwunel's server admin room, `<server> Admin Room`,
`#admins:<server>`, version 11, ID `!opaque:server`. Tuwunel 1.9.4's
src/service/admin/create.rs makes it with `RoomId::new_v1` and `RoomVersionId::V11`, and joins a
new server admin to it. `joined_rooms()` checked every entry with `is_room_id`, the bus's
version-12-only grammar, so the one foreign room refused the whole answer; its only caller is
`_find_side_room`, which runs while a side-room ID file is absent, so every team hit it at its
first side-room creation.

Fix, per the coordinator's narrowed scope: `is_room_id` is unchanged (every bus room is version
12). A new `protocol.is_any_room_id` is the spec's grammar for every room version (v12 shape, or
`!opaque_id:server_name`, at most 255 bytes); `joined_rooms()` refuses an answer only when an
entry fails that, returns the version-12 IDs as candidates and the rest separately, and
`_find_side_room` names the rest on stderr (not in the changes list, which drives the play's
changed status). `_is_side_room` reads the create event allowing 403 and 404 and treats either as
"not a side room". Red reproduced with the exact host error (27 of 27 side-room tests) once the
fake joined each admin to a version-11 admin room.

DBF: class "a homeserver list validated with the bus's own narrower identifier grammar, so one
foreign item refuses the whole answer". Rule `homeserver-list-narrow-grammar` is a test-based
AST check (tests/helpers/pingbus/test_identifier_grammar.py, documented in CLAUDE/QA.md), red
commit 4cd5167b on the one instance, admin.py:417. The independent search found 13 sites and
the same single wholesale instance; the rest are per-item skips or bus-written data. No Go code
reads homeserver lists (the two Go room-ID regexps read member.json).
