>   down the file. A file with no sentinel line above predates this system —

>   one-line takeaway above the fence.

and stage 1.

`cmd_ask_human` (the text and exit code are unchanged; `test_cli_rooms` asserts the whole line),
and listed in the rule's `OWNED`, so a checker that copies it is reported. EXIT_RATE is read from
cli.py the way `a3_join` reads EXIT_OK. `helpers/pingbus` is in the image: CCY 3.100.14,
container 2.79.9.

`subagent-reports/261023-lxc-attach-stderr-independent-search.md`).
