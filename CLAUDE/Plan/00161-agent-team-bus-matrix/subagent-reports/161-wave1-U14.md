## Review

**Verdict: FIX.** The code matches the design and protocol, but there is one real correctness gap and two tests that cannot fail.

The checks that passed: stdlib-only, no install-specific data, no QA suppressions, and nothing written to stdout. The handle and `--host` grammar matches PROTOCOL.md section 3, and the allowlist shapes match section 11. `resolve_host` refuses when there is neither a role nor a `--host`, and a test covers that. Duplicate-key decoding fails as it should in both loaders.

1. **Two concurrent registry updates can hand out the same `<n>`** (`helpers/agent_bus/registry.py:214-249`). `load_registry`, then `add_member`, then `save_registry` is a read-modify-write with no lock. Two `add-member` runs at the same time can both read counter k, and both issue `<repo>.<k+1>+…` for the same seat. That breaks "`<n>` never reused" (DESIGN section 4).
   - Fix: add a `locked_registry(path, team)` context manager that takes `fcntl.flock(LOCK_EX)` on a sibling `registry.lock`. It should yield the loaded registry and save on clean exit.
   - Test: a second process cannot get the lock while the first holds it.

2. **The NaN test cannot fail** (`tests/helpers/agent_bus/test_teamfile.py:218-220`). The NaN is placed under the unknown key `"port2"`. If `parse_constant` is removed, `parse_team_file` still raises `TeamFileError` for the unknown key, so the test stays green.
   - Fix: assert `self.assertRaises(ValueError): teamfile.decode_strict_json('{"a": NaN}')`. Or put the NaN in a key that is valid apart from the NaN.

3. **The query check is untested** (`tests/helpers/agent_bus/test_teamfile.py:174`). `"https://api.github.com/?x=1"` is already refused for its trailing `/`, so deleting `or parts.query` (`teamfile.py:256`) leaves the test green. The fragment rule has no case at all.
   - Fix: use `"https://api.github.com?x=1"` and add `"https://api.github.com#f"`.

4. **Dead code** (`helpers/agent_bus/registry.py:49`). `_REPO_PART_RE` is compiled but never used. Delete it.

5. **Code only the tests use** (`helpers/agent_bus/teamfile.py:85-87`). Nothing outside the tests calls `TeamFile.listen_addresses()`. Keep it only if U15's renders will use it. Otherwise remove it and its test (`test_teamfile.py:89-91`).

6. **Duplicated grammars** (`teamfile.py:24-32`, `registry.py:28-43`). These are copied from PROTOCOL.md because U02's `protocol.py` has not landed. The docstrings record the follow-up. The coordinator should track the switch to imports when U02 merges, so the two copies cannot drift apart.
