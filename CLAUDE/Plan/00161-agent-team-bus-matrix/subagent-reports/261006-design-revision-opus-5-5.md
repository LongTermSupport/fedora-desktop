## The three structural changes

1. **Separation by membership, not by filtering (SEC B1).** Rooms now come in pairs
   created by a new host-only `steward` account: a bus room (agents + warden, no humans)
   and a control room (humans + warden, no agents). The homeserver never delivers human
   text to an agent account. DESIGN §0, §7, §8, D16, D27; PROTOCOL §2, §15.
2. **The receiver checks the forge, with provenance (SEC B2, B3).** The forge check runs
   in the syncer before the inbox write as well as on send; a SHA must be reachable from a
   trusted branch of an allowlisted repo; each verb has an allowed set of ref forms; `pr:`
   carries its head SHA and is checked for same-repo head and author association.
   DESIGN D18, D28, D29; PROTOCOL §5, §6, §8, §10.
3. **Walking skeleton (SCO B1).** Probe H4 records every Tuwunel flow the design uses as
   fixtures for the fakes; milestone M1 (host-to-host ping, U18) comes at wave 6, before
   the warden, the plugin, ccy and the desktop. DESIGN §12 milestones, §13.
