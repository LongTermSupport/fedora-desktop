# Plan 00161 — Journal 26-10-07

_Scaffolded by `mkplan.bash`; timestamps in this file are UTC._

> **Append-only activity log** for plan 00161. One file per day
> (`00161-Journal-YY-MM-DD.md`). `PLAN.md` tracks the plan (what/why,
> current state, tasks); this journal tracks what actually *happened* —
> findings, decisions, dead-ends, hand-off state — the linear lifecycle a plan
> document structurally cannot carry.
>
> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier
> entries (corrections are new entries):
>
> ```
> ## HH:MM · category · REF   — optional short title
> ```
>
> - `HH:MM` UTC 24h (the date is in the filename, also UTC); times increase
>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).
> - `category` ∈ `action` | `finding` | `decision` | `thought` | `blocker` | `handoff`
> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

## 09:01 · finding · —   — Host run 2: U01 complete, ccy address settled, H2 docker image

Second host run through meta-deploy (after the sbin and U01 fixes).

U01, all four sessions, authenticated with the ccy token: SessionStart, UserPromptSubmit, Stop
and SessionEnd all fire, Stop once per completed turn. A bypass-mode session without
`crossSessionInbound: accept` holds a notice (`no-mode-asserted`); default mode routes it with
or without the setting, so the ccy entrypoint and `agent-bus-claude` passing the setting is
required, not optional. An identical notice body is dropped as a duplicate for longer than
20 s and at most 33 s; two notices 0.05 s apart reach the model as separate entries and
separate turns. The socket is gone by the time the session exits. U01 is complete.

throwaway team, the second run (nothing changed), `check`, `remove --purge` and the three
play legs (change, no change, absent with a change) all passed. H1's dummy leg reached

`<bus_ip>`; the host's primary address was refused from all three. That settles DESIGN §5.3:
the ccy `base_url` is the bus address and §12 needs no `host.containers.internal`
exception. H2: an LXC guest reached both the primary and the bus address; libvirt's network

property set per family once per line); it now joins them onto the CHECK line.
