# Plan 00161 — Journal 26-10-07

_Scaffolded by `mkplan.bash`; timestamps in this file are UTC._

> **Append-only activity log** for plan 00161. One file per day
> (`00161-Journal-YY-MM-DD.md`). `PLAN.md` tracks the plan (what/why,
> current state, tasks); this journal tracks what actually *happened* —
> findings, decisions, dead-ends, hand-off state — the linear lifecycle a plan
> document structurally cannot carry.
>
> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier
> entries (corrections are new entries):
>
> ```
> ## HH:MM · category · REF   — optional short title
> ```
>
> - `HH:MM` UTC 24h (the date is in the filename, also UTC); times increase
>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).
> - `category` ∈ `action` | `finding` | `decision` | `thought` | `blocker` | `handoff`
> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

Third host run through meta-deploy. deploy.bash passed every leg: the installer and play

H2 is now complete apart from the libvirt guest owner step: a docker container reached the
primary and the bus address, the source seen being the docker bridge's own address, so a team
with docker members lists that bridge's subnet in `allow_from`, as README.docker says. LXC
as before.

acceptance.bash (M1) stopped at its first member leg. Each member is a `systemd-run`
service with DynamicUser=yes, which extracts its own bundle so it owns the token; `tar -x`
created the bundle's directory and then failed to open each file with "Function not
implemented" (ENOSYS). DynamicUser implies RestrictSUIDSGID, whose seccomp filter answers
openat2 with ENOSYS (it cannot inspect openat2's mode), and the file opens are the calls
that failed, so GNU tar is taken to use openat2 there. The member now extracts with Python's
tarfile (plain openat) and the `data` filter, checked outside systemd to keep the bundle's
700/600 modes. The cleanup on the way out removed the members and the team. Re-run pending.

## 11:50 · finding · —   — Host run 4: first ping crossed; ack lost its event ID

Fourth host run. deploy.bash passed again. acceptance.bash got past the members' bundle
extraction (Python's tarfile works under the members' service): both members passed
`config check` and joined the team room, and the first real ping crossed the bus: member
a's `send review <path ref>` was received by member b's `wait`, exactly as sent.

It stopped at b's `ack --re <event>`: pingbus said `--re` expected one argument. Member
commands run through `systemd-run`, which expands `$NAME` in the command line the way
ExecStart= does, and a Matrix event ID starts with `$`, so the unset "variable" expanded to
nothing. member_run now passes `--expand-environment=no` (systemd 254 and later). The
cleanup on the way out removed the members and the team. Re-run pending.
