# Plan 00179 — Journal 26-10-17

_Scaffolded by `mkplan.bash`; timestamps in this file are UTC._

> **Append-only activity log** for plan 00179. One file per day
> (`00179-Journal-YY-MM-DD.md`). `PLAN.md` tracks the plan (what/why,
> current state, tasks); this journal tracks what actually *happened* —
> findings, decisions, dead-ends, hand-off state — the linear lifecycle a plan
> document structurally cannot carry.
>
> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier
> entries (corrections are new entries):
>
> ```
> ## HH:MM · category · REF   — optional short title
> ```
>
> - `HH:MM` UTC 24h (the date is in the filename, also UTC); times increase
>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).
> - `category` ∈ `action` | `finding` | `decision` | `thought` | `blocker` | `handoff`
> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

- No change to stt: it already treats a manifest that is not COMPLETE, or a part not yet synced, as waiting (S5); fails on a size or MD5 mismatch (S6); and sends a loose audio file without a manifest as it is (S8). So manifest verification is already "when there is one".
- Polled by a user timer (5 min), not a .path unit: inotify on an rclone FUSE mount does not fire for files that arrive from the remote. A Drive file appears in the mount only once its upload has finished, so a loose file is never seen half-uploaded.
- Folders come from stt_watch_folders in host_vars (install paths, never in the repo), templated into the service's ExecStart with % and $ escaped; the play asserts absolute paths with no double quote, backslash or newline. The first spelling of that check let a backslash through (Jinja unescapes \\ before re sees it); found with a scratch play over six cases, fixed with \\x hex escapes, the six cases re-run correct.
- Failure is loud: OnFailure raises a critical notification. Known trade-off kept: stt stops at the first failure, so a corrupt recording holds back later ones until moved aside.
- systemd-analyze --user verify passes on the rendered units.
