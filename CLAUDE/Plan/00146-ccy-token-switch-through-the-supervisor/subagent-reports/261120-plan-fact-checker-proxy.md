## REFUTED / needs correction

1. Task 1.3 (changed line): "confirm children get the placeholder, `HTTPS_PROXY` and `NODE_EXTRA_CA_CERTS` (it reads `/proc/1/environ` today)". The parenthetical is true only for the token. `files/opt/claude-yolo/optional/child-claude/bin/ccy-claude:98` greps `/proc/1/environ` for `CLAUDE_CODE_OAUTH_TOKEN` alone, and only when that variable is unset (line 80). Lines 10-14 say that exactly two names are missing from the agent shell (the token and `GH_TOKEN`); every other variable is inherited. So HTTPS_PROXY and NODE_EXTRA_CA_CERTS reach children by plain inheritance, not through /proc/1/environ. The placeholder is the one value that needs the /proc path. Change: reword so it does not imply ccy-claude recovers the proxy variables. The task also has to cover that ccy-claude exports the placeholder it reads from PID 1.

## Not changed by the diff, but wrong (context line, same area)
