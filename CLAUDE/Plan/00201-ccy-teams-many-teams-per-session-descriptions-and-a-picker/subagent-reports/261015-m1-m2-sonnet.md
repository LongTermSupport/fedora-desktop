## Deviations and observations

- S-A15's question names what the team trusts, but no source for those words was specified: added
  `declare.py undescribed` (`UNDESCRIBED<TAB>team<TAB>words`), parallel to `limited`.
- S-A6: `describe` prints `CHANGED<TAB>team T description` with no `, in <file>` tail, as the spec
  words it (the other edit commands print the path).
- declare.py now reads a double-quoted scalar as the JSON string it is: a `#` inside the quotes is
  text, not a comment (a description such as "Fix bug #5" would otherwise be cut).
- A vaulted description shows as `-` in `declared`, so one unreadable entry does not end the listing.
- S-A10 specifies `ABOUT<TAB>1<TAB>...` (the version field of the section-15 lines) although the other
  `status` lines carry none. Built as specified; flagged for the owner.
- `undescribed` was written in one step with its Go client test; every other layer was seen red first.
- Not run here: the live host (deploy, an applied description, Element showing the topic). That is
  M7. Deploy order matters: this image must reach every member before any team sets a description.
