## 11:20 · finding · P1 — repo-side facts and the working hypothesis

Written from the CCY container, so nothing here is a host observation.

- The repo writes no Dash to Dock dconf keys at all; the extension runs on upstream
  defaults (`intellihide-mode = FOCUS_APPLICATION_WINDOWS`).
- The repo's terminal is Ptyxis (`play-gsettings.yml`), not `gnome-terminal`.
- Working hypothesis H1: in the default mode Dash to Dock only checks windows of the
  app GNOME Shell's window tracker considers focused; if the Ptyxis window is not tied
  to a desktop file, the dock never tests it and stays put. `ALL_WINDOWS` sidesteps the
  tracker entirely, so it is the proposed fix whichever of H1/H2 triage confirms.

## 12:05 · finding · — — a literal backtick anywhere in a bash file breaks the semgrep gate

qa-patterns.bash reported "semgrep could not parse probe-dock.bash" with no line
number. Bisected with `semgrep --dump-ast -l bash`: the file parsed once the two
`out '```'` fence lines and an escaped backtick in a double-quoted string were gone.
Fix: build the fence from octal escapes (`printf '\140\140\140'`) and drop the
inline backticks. Worth remembering for any plan script that writes markdown.
