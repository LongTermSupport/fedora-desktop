# Fact check: Task 1.3 traffic probe edits (commit 6f26f5cef)

Judged against committed HEAD on v2-smoke with `git show HEAD:<path>` and `git grep HEAD`.
Scope: the diff's added or changed claims in PLAN.md and bus-host-commands.md, and the
meta-deploy.list note from the same commit.

Summary: 21 claims: 19 verified, 1 refuted (imprecise wording), 1 unverifiable-here.

## REFUTED (most consequential first)

R1. PLAN.md, "Receipts are counted as `teamchat.receipt` events and presence changes as
membership events". Presence is not counted as membership events. The code and
bus-host-commands.md count `m.room.member` events (join, leave, invite, ban, knock) as the
membership change. Presence is listed in `notCounted` (`traffic/output.go:13`) and in the
doc's "Not counted" bullet. The next clause of the same PLAN sentence says presence is in no
history, so the sentence contradicts itself. Change: say "membership changes (`m.room.member`)
stand in for a seat starting or stopping; presence is not counted".

Minor imprecision (not refuted): the doc says paging runs "until a page holds an event older
than `--since`". `readRoom` (`traffic/traffic.go:189`) also stops when the history ends, which
is when `End` is empty or the chunk is empty. This is harmless.
