## 19:41 · finding · 2.0b   — ccy-teams launch-start check: a recorded time bounded by reads of the real clock

The ccy-teams suite's launch-start check (`scripts/test-ccy-teams.bash`, the case "with the seats, the
session and the launch's start") failed on two CI runs that did nothing wrong, one of them on a branch
whose push run had passed it, and passed on a re-run each time. It is Task 2.0b's own check.

**Class: a test asserts that a time the code under test recorded lies inside a window the test
bounds with reads of the real clock.** The code reads the clock in one process, the test reads it
in two others, and the assertion holds only if the wall clock moved forward and was read in that
order. Nothing guarantees it: the wall clock is not monotonic (a step by time sync on a VM runner
puts the recorded value outside the window), and three `date` processes under load are three reads
at unrelated moments. A failure is a coin that comes up rarely and can never be reproduced on
request: 88 local runs, alone and under load, did not fail once, so the cause on the runner is
unproven and is stated here as the hazard, not as an observed fact.

**Detector:** the semgrep rule `bash-test-time-window` (`.semgrep/bash-conventions.yml`, fixtures in
`.semgrep/bash-conventions.bash`): a test (`[ ]` or `[[ ]]`) whose bound is a `date` command
substitution (`-le` or `-lt`). It is red on the defect and nothing else in the repository matched
(one finding, this line); a bound on elapsed time (`$(date +%s) - started`) and a line annotated
`# FAIL-FAST-OK:` are not flagged. It runs in `scripts/qa-patterns.bash`, which every QA run and CI
run executes.

**Fix:** the suite owns the time. A fake `date` in the suite's fake-binary directory prints
`FAKE_NOW_MS` for `date +%s%3N` when a test sets it and is the real `date` otherwise; the test sets
a fixed millisecond value and asserts that the launcher passed exactly that value to
`pingbus seat disconnected`. The shape of a real clock value (thirteen digits) is still asserted on
the runs that use the real clock. The suite passes, 252 checks.
