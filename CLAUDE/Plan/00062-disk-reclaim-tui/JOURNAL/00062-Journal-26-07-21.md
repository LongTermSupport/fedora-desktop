## 10:10 · finding · — — host deploy blocked then unblocked (fact cache)

Host `ansible-playbook` failed at task 1 with `The module interpreter
'/usr/bin/python3.11' was not found` (rc 127) — NOT a defect in the play. Root
cause: `ansible.cfg` caches facts in `untracked/facts/`, and a pre-F44-upgrade
run had cached `ansible_python_interpreter=/usr/bin/python3.11` (system Python
removed by the upgrade; the user's `python3.11` is only a pyenv shim at a
different path). `rm -rf untracked/facts/*` cleared it and the play deployed.
Documented as `post-upgrade.md` step 2b in a separate commit (`05eba16`).
