- If gh is already there, it does nothing. Otherwise:
  - on Ubuntu or Debian it adds GitHub's apt repository (`cli.github.com/packages`, installing curl first if needed);
  - on Fedora or EL it adds GitHub's `gh-cli.repo` to dnf, the same repository the host play uses;
  - on Alpine it installs `github-cli`.
- A container with none of those package managers is refused, and the message says so.
