## 19:38 · finding · —   — Issue 101 boundary research merged

Issue #101 research merged: [RESEARCH-cc-boundary.md](../../RESEARCH-cc-boundary.md).

It recommends launching a `cc --teams` session as a `systemd-run --user` transient service with `InaccessiblePaths=` over Element's folders. That is a mount-namespace boundary that covers file tools, Bash, children, MCP servers and hooks, and it leaves the network alone.

systemd.exec(5) confirms that user services get these options through an implied `PrivateUsers=`. A probe on this desktop is still needed.

The residual is the session bus: the session can itself run `systemd-run --user` and start an unrestricted service. Hiding the bus closes that, at the cost of D-Bus clients inside the session.
