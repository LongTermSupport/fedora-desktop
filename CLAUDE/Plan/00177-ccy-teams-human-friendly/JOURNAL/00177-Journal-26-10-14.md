# Plan 00177 — Journal 26-10-14

_Scaffolded by `mkplan.bash`; timestamps in this file are UTC._

> **Append-only activity log** for plan 00177. One file per day
> (`00177-Journal-YY-MM-DD.md`). `PLAN.md` tracks the plan (what/why,
> current state, tasks); this journal tracks what actually *happened* —
> findings, decisions, dead-ends, hand-off state — the linear lifecycle a plan
> document structurally cannot carry.
>
> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier
> entries (corrections are new entries):
>
> ```
> ## HH:MM · category · REF   — optional short title
> ```
>
> - `HH:MM` UTC 24h (the date is in the filename, also UTC); times increase
>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).
> - `category` ∈ `action` | `finding` | `decision` | `thought` | `blocker` | `handoff`
> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

## 12:01 · action · P6   — Phase 6 built: menus on Enter

Phase 6 built (Tasks 6.1 to 6.3), awaiting the owner's second host test (6.4).

- Enter on any row opens a menu of that row's actions in words, each with its shortcut
  beside it; Esc or the Back row returns to the board. Ctrl keys still work as shortcuts
  straight from the board. Every key (Ctrl-N, R, X, E, P, U and ?) is in a menu of the rows
  it acts on, and a test fails if one is in none.
- The header gains a line naming the selected row's actions, swapped as the cursor moves
  (fzf transform-header on the focus event, needs fzf 0.45 or later; the unit test cannot
  run a real fzf, so the owner's host test is the proof).
- A person with at least one Element session sees Open Element first; the password is a
  separate entry that names how many sessions it signs out and asks first (default No). A
  person with none sees Sign in first, asked nothing, and Element is offered right after the
  password is shown.
- Opening Element no longer ends ccy-teams: it starts apart (as before), the device counts
  of that team are forgotten, and the board reads them again.
- Deliberate parity-suite changes: Enter on a seat or team now opens the menu (the suite
  picks Attach or the help from it); the human row's WHERE text is "Element; Enter for
  choices"; the fake fzf's EXIT answer picks the last row (a menu ends in Back to the list).
