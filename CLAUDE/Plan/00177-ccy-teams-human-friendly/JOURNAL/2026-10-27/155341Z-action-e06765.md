## 15:53 · action · —   — Task 13.1: the create wizard asks GitHub as every gh login

Task 13.1, from the owner's report: `ccy-teams create` refused the owner's own checkout three
times ("not found, or your gh login cannot see it"). The wizard ran plain `gh api`, so it
asked GitHub as gh's active login, and on a host with several logins that was not the
owner's.

Every gh call in ccy-teams is in `internal/teams/create/wizard.go`: `needGh`, `checkOwner`
and `checkRepo`. All three now ask as each working login from
`gh auth status --json hosts`. Each login's token, from `gh auth token --user <login>`, goes
in as GH_TOKEN through an `execx.Secret`. gh's active account is never switched. The new
`internal/ghlogin` package holds the parse, the read and the token. They came from
`internal/ghaccount`, which now uses them.
