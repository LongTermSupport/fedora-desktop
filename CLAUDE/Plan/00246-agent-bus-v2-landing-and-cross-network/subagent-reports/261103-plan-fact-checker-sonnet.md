# Plan fact check: Plan 00209 diff (Phase 8 moved out) and the new Plan 00244

Scope: (1) the claims the diff `00209-agent-bus-v2-in-go.diff` adds or changes in Plan 00209's
PLAN.md (Status line, Task 6.3 sentence, Phase 8 pointer, removed size declaration); (2) the whole
of Plan 00244's PLAN.md. Tree judged: branch `spike/v2-merge-up`, working tree (the
`livenessAllowances` and `realClocks` rows, the GoProjectRules.md text and the `.golangci.yml`
tagliatelle comment were uncommitted or staged at check time; another session was editing and
staging while this ran). Read-only apart from this report. No test or QA run was started.

Paths are repo-relative. Counts that describe the tree as it was before the fixes cannot be
re-measured from the fixed tree; they are checked against the journal and the pull request.

## REFUTED (most consequential first)

### R1. Plan 00209 Task 6.3 names the wrong place for the decision: "Plan 00244 Task 8.1"

The sentence says v2's landing accepted the second owners (`lxccmd`, `teamchat/units`, the
`dynamicNames` row) by "the owner's decision of 2026-11-03, Plan 00244 Task 8.1". Plan 00244 Task 8.1
(PLAN.md lines 43-57) says nothing about second owners, `lxccmd`, `systemctl` or `dynamicNames`; a
search of the plan for those words finds none. The decision exists, but in the pull request 124
comment "The owner's decisions (2026-11-03)", item 5: "accepted for now. Add a Plan task: collapse
them to one owner each when v1 is retired (Task 6.3)". Nothing in a tracked file records it
(`git grep "second owner"` finds the v2 specs, the reports and the 2026-11-02 journal entry that left
it as a question, none of them the decision).

Changes in the plan: either cite "pull request 124, owner decision 5" in Task 6.3, or add the
decision to 00244 (Task 8.1 or a line under Goals) so the pointer is true. The facts about the
second owners themselves are right (rows 5-8 below).

### R2. Plan 00244 Overview: "this plan links them and does not copy them"

00244's PLAN.md contains no markdown link at all (`grep -c '](' PLAN.md` is 0). It names Plan 00209,
direction 7, SPEC-matrix M50 and M51, Task 0.6 and GoProjectRules.md in prose only. The "does not copy"
half holds. Changes in the plan: add the links the sentence promises (at least
`../00209-agent-bus-v2-in-go/PLAN.md`, `../00209-agent-bus-v2-in-go/SPEC-matrix.md`) or say "names".

## Observations that are not claims

- **Size.** The diff removes Plan 00209's `MUST_EXCEED_PLAN_SIZE_BECAUSE` declaration (the pull request's
  default 08 said to drop it). PLAN.md is now 571 lines and 47,579 bytes. The daemon's documented tiers
  (`PlanJournalling.md`, "Size tiers on PLAN.md") are Block above 35,000 bytes or 900 lines, "whichever
  comes first"; I found no override in `.claude/hooks-daemon.yaml`. So the plan is in the Block tier on
  bytes: shrinking edits stay silent, but the next edit that grows it can be denied, and the removed
  reason ("still open in Phases 2, 3 and 8") is now true of Phases 2 and 3 only. Not a factual error; a
  consequence the owner's "drop it" may not have weighed.
- **Task 8.6 wording.** "The v2 lines that were lost are back" holds with one deliberate exception that
  the plan does not state: v2's teamchat-only `project_realtime_bound` text and fixtures were not put
  back, because F44's module-wide rule replaced them (journal `2026-11-02/213016Z-correction-75770e.md`
  records it for `src-go/CLAUDE.md` and the fixtures; the fixtures `fix/internal/teamchat/realtime` and
  `realclock` are gone from the tree). The earlier report `261102-plan-fact-checker-sonnet.md` R1 raised
  this. Its R2 (the `git diff F44...feat/bus-v2-n3e` command without `origin/`) is moot: 00244 dropped
  that sentence.
- **Stale labels.** `CLAUDE/GoProjectRules.md` lines 359, 696 and 939 and the 2026-11-02 journal entries
  say "Plan 00209 Task 8.x". They resolve through 00209's pointer (PLAN.md lines 551-555), so 00244's
  "still resolves" holds (row 24), but each takes a hop.
