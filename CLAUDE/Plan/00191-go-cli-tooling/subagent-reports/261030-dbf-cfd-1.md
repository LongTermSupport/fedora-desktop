  `errFailed` to `errors.Is` (sudo has already explained it) and whose text is the cause.
- app.go:310 `findUploadDir`: getent exit 2 (no such key) is still "'camera' user not found";
  any other failure is `ERROR: could not look up the 'camera' user: <err>`.
- app.go:359 `dispatch`: a failure no step printed is printed as `ERROR: <err>` (E64) by the new
  `c.report`, which prints nothing for `errFailed`/`printed`.
- network.go:53: `WARNING: could not list the active connections, so no hotspot is used: <err>`.
- network.go:59: the ipv4.method warning carries the error (`nmcli exited N: <output>`).
- network.go:96 `firstIPv4` now returns its error: detectHotspot warns
  (`WARNING: could not read the address of '<dev>', so no hotspot is used: <err>`); localIP fails
  with `ERROR: could not read the IPv4 address of <dev>: <err>` (no longer "has no IPv4 address").
- network.go:181: `ip route` failing is `ERROR: could not read the default route: <err>`, not the
  three-line "No default network interface" guess.
- network.go:219, 230 `apSupported` returns why it is unknown; the "could not determine" note
  is followed by the failing programs' errors, one per line.
- prune.go:99: `  failed  <path>  (sudo exited N)`.
- remote.go:78 `findMount`: findmnt exit 1 (nothing matched) is still "No rclone mount found";
  any other failure is `ERROR: could not list the rclone mounts: <err>`.
- remote.go:86: each mount whose source could not be read is listed under the not-found error
  (`  could not read the source of <mnt>: <err>`).
- remote.go:218: `ERROR: Failed to copy files to mount: <err>`.
- remote.go:236: `Verification failed: <how rclone ended>` (new `howEnded`: exit code or signal
  without the output, which is printed below it as before).
- server.go:70, 77: teardown and prepare errors go through `c.report`.
- teardown.go:36: the sort-pass note carries an unprinted cause (`unprinted(err)`).
- teardown.go:197: `could not read upload status: <err>`; the guess ("no matching mount, or the
  rclone RC is unreachable") is gone.
- upload.go:257: `<mount> is no longer served by an rclone mount: <err>`.
- verify.go:83, 87: `completeness`/`exifComplete` return `(verdict, error)`; an unverifiable
  arrival whose exiftool failed prints `(the completeness check failed: <err>)` instead of
  `(no completeness check for this type)`; `--sort` prints
  `  note: <name> could not be checked for completeness: <err>` on stderr; a file that cannot be
  stat'ed is still truncated, with the stat error returned.
- wifipass.go:120: root's failure message adds `(as the user: <err>)` when the user's read failed.
- Exposed by the `ready` change (now a command-error wrapper): teardown.go:46 and server.go:617
  return `sudo is not ready: %w`; app.go:236 (findUploadDir's caller) calls `c.report`.
