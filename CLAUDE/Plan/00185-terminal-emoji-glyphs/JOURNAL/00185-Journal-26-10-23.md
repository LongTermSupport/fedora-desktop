# Plan 00185 — Journal 26-10-23

_Scaffolded by `mkplan.bash`; timestamps in this file are UTC._

> **Append-only activity log** for plan 00185. One file per day
> (`00185-Journal-YY-MM-DD.md`). `PLAN.md` tracks the plan (what/why,
> current state, tasks); this journal tracks what actually *happened* —
> findings, decisions, dead-ends, hand-off state — the linear lifecycle a plan
> document structurally cannot carry.
>
> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier
> entries (corrections are new entries):
>
> ```
> ## HH:MM · category · REF   — optional short title
> ```
>
> - `HH:MM` UTC 24h (the date is in the filename, also UTC); times increase
>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).
> - `category` ∈ `action` | `finding` | `decision` | `thought` | `blocker` | `handoff`
> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

## 14:45 · finding · —

The first host run failed 6 of 17 acceptance checks: the cache recorded und-zsye, not en, for
Noto Color Emoji, and Symbola won U+1F4C8, 1F4CA, 1F4E6 and 1F528. Found read-only on the
host: the run started from a cc session, whose umask is 077 (Plan 00098). Ansible inherits
the caller's umask and sudo only adds 022 to it, so the root `fc-cache -f` rewrote 40 of the
41 files in the system font cache 0600. The desktop user could not read them, and fontconfig
used the user's own cache, still valid and holding the scan from before the file.

DBF remediation (Task 2.3). Class: Ansible runs with the umask of the shell that started it,
so a root task that writes a file with no mode takes the caller's umask. Defence: the rule
ansible-umask-pinned (tests/helpers/umask_pin/, CLAUDE/QA.md), red first on ansible.cfg and
on a real probe play whose files came out 0600. Fix: the umask_pin callback, enabled in
ansible.cfg, sets 022 before any task, for every launcher. play-fonts.yml now also rebuilds
the user's own cache, and rebuilds both whenever a system cache file is unreadable by other
users, so its next run repairs the damage. play-basic-configs.yml sets explicit modes on yq
and /etc/vimrc.local, which a `creates:` or an existing file would otherwise never repair.
acceptance.bash adds check 18 (the system cache is readable); triage lists unreadable files.
