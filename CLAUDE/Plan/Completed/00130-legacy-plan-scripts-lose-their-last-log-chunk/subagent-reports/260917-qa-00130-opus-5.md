1. **The gate examines 52 of the 67 `.bash` files in the non-`Completed/` plan tree,
   and its pass line does not say so** — `scripts/qa-plan-script-logging.bash:94`.
   `for script in "$planDir"*.bash` is top-level-only, and `CLAUDE/Plan/[0-9]*-*/`
   (line 91) excludes `Cancelled/`. The 15 files outside the examined set, computed by
   diffing the two sets rather than comparing totals:
   - 11 under `CLAUDE/Plan/00099-rclone-rc-auth-broke-unmigrated-clients/falsification/`

   None currently carries the pattern, so this is a hole, not a live offence — but a
   plan that puts its scripts in a subfolder (00099 already does) reintroduces the
   pattern with the gate printing a confident green. Fix: recurse
   (`find "$planDir" -name '*.bash'`), and make the pass line state its scope, e.g.
   `COVERAGE: 67 of 67 plan scripts in the active tree (Completed/ excluded by design)`.
   This is the repo's recurring class — the commit message argues for stating the
   count, then states a count whose denominator is unstated.

   close, reproduced one level down. Fix: `find "$planDir" -type d -name logs`.

   Success Criterion "No `logs/` directory remains under `CLAUDE/Plan/NNNNN-*/`" reads
   as tree-wide and is only true for the glob it chose. Either relocate these too, or
