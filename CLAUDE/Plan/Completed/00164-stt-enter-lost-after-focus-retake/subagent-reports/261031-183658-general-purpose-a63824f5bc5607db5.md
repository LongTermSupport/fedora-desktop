**The fix** (`src-go/internal/wsi/paste.go`, `beforeEnter`): whenever an Enter or a save is still to be sent, the panel is asked again before the key, whatever happened before the paste. If the window closed, lost focus or shows another tab, the key is not sent and the existing "The text was pasted but not sent: …" notification is shown.
- **Wait:** the 1 s wait stays only after a retake, where whatever took focus during the dictation can take it back. Every other paste keeps the 0.3 s wait, with no added delay.
- **Two gaps the old code also had:**
  - A save alone (`--no-auto-enter` with Ctrl+S) is now checked too; before, it was never checked.
  - The re-check is skipped without `--paste-with-shift`, because then no window was recorded when Insert was pressed, so there is nothing to ask about.
