**What changed:**

A pick that cannot be read or parsed is exit 2, and the gate's output on success is unchanged. A change to an optional play now reruns this gate in `qa-changed`. The gate's real-tree test now also copies `playbooks/imports/optional`.
- **Attendant.** A prompt can now build its answer from what was printed before it, and the output it keeps grew from 1 KiB to 16 KiB so a full menu fits. If it cannot build an answer, the run ends as a fail and the transcript says why.

It finds each pick by the same label the menu shows; I exported that function from the consumer package as `consumer.MenuLabel`. A pick the menu does not offer, no menu, or a menu not numbered 1 to n ends the run.
