> ```

>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).

> - `REF` = optional task/phase ref (`T1.2`, `P1`) or `—`.
> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

## 14:15 · finding · —

First host deploy failed at "Assert ImageMagick can write WebP". The regex assumed `magick -list format` puts the mode right after the format name. A modular ImageMagick build (Fedora) adds a Module column between them, so the regex never matched although WebP works. The container build has no Module column, which is why it passed here. Fix: the probe now encodes a 1x1 WebP to /dev/null and asserts rc 0, showing stderr on failure. Tested in the container: rc 0 for webp, rc 1 with "no encode delegate" for an unknown format.
