distinction is the entire subject of this plan, so blurring it here would be
self-defeating.

Not fixing `ruff not installed`: it is a real IaC gap, `exit 2` is the correct
fail-fast behaviour, and it is an explicit Non-Goal.

## 22:26 · finding · — — same class, found in our own docs, deliberately NOT fixed

While writing the `CLAUDE/QA.md` note I hit this in the existing gate table:

> `qa-bash.bash` … shellcheck (only when `shellcheck` is in PATH — silently
> skipped if absent)

That is the same defect this plan is about: `qa-bash` treats its analyser as
optional (absent ⇒ writes `[]`, still reports a pass) while `qa-python` treats
its analyser as required (absent ⇒ exit 2). On a box without `shellcheck`,
`qa-all.bash` goes green with **no static analysis of its bash at all**. The
zero-file guard does not catch it — the file count is non-zero; it is the
*analysis* that is missing.

Left unfixed on purpose, and said so out loud in both `PLAN.md` and `QA.md`
rather than quietly folding it in: making `shellcheck` required is an IaC
question about the gate's declared dependencies with a far wider blast radius
than a path-matching bug, and it belongs with the `ruff` gap in its own plan.
Recorded so it is tracked, not stranded in a session transcript.

that already had one, and left the actual gap in place. Corrected in `PLAN.md`'s
Non-Goals too, since a stale Non-Goal would send the next reader hunting for a gap
