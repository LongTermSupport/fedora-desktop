## 20:45 · finding · — — the failure, and where it lives

Operator report from a headless VM: `ccy` prints the custom-Dockerfile banner, then
`Error: stat /dev/dri: no such file or directory`, exit 125. The launcher's `podman run`
carries `--device /dev/dri:/dev/dri` unconditionally (one literal line in the run argv);
podman stats the device before creating the container and aborts when it is absent. No DRM
driver, no `/dev/dri`: every headless server and every serial-console VM. The Wayland/X11
socket mounts beside it were already conditional; the device was the one hard requirement.
