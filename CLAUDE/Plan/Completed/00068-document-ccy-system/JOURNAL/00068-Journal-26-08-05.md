## 07:05 · finding · P4 — adversarial review found six real defects

Ran a 10-agent workflow: 7 sonnet ground-truth verifiers (one per claim group,
each checking the doc against source) + 3 fable clarity reviewers
(newcomer / honesty / structure). 40 findings. I re-verified every high-severity
claim against the source myself rather than trusting the agents — all six below
were confirmed real:

1. **`--no-cache` does not exist as a user flag.** I had invented it from
   `claude-yolo:1389,1416`, where it is hardcoded *inside* the `--rebuild` build
   call. The arg-parsing loop has no such case; `ccy --no-cache` would be
   forwarded to `claude` and rejected. **Deleted the row.**
2. **The launch sequence was in the wrong order.** Real order is SSH selection
   (`:865`) → token selection (`:956-1024`) → root/UID guard (`:1174`) →
   version check (`:1436`) → project image resolution (`:1453`). I had token
   before SSH, the root check in step 1, and image resolution before the version
   check. **Rewrote the sequence.**
3. **The security model omitted the GUI and GPU exposure.** `claude-yolo:2704`
   bind-mounts the Wayland socket (or `/tmp/.X11-unix` at `:2724`) and `:2773`
   passes `--device /dev/dri` — unconditionally, on every desktop session. The
   "what the container CAN reach" table claimed to be exhaustive and listed
   neither, nor the `~/.gitconfig` copy. **Added all three.**
4. **The gitignore safety check blocks, it does not warn.** `claude-yolo:59`
   calls it as `check_ccy_gitignore_safety || exit 1`, and
   `lib/common.bash:268` prints "CCY will NOT start until this is fixed."
   **Corrected, and named the actual whitelist it enforces.**
5. **The supervisor dry-run advice was backwards.** `ccy_supervisor.py:73-76`
   hardcodes `--arm --` in `_ARMED_WRAPPER_LINE`, and both `deploy_supervisor:
   true` *and* an absent key deploy-and-arm. A project set up this way starts
   **armed**, not in dry-run. **Corrected, and documented the three-state
   config.** Also flagged that `--supervise` alone sets a bare
   `claude-supervise --` that the image does not vendor.
6. **The containment framing overclaimed.** The mounted SSH key and `gh` token
   are account-wide credentials, so "worst case is damage to the project" was
   not earned. **Added an explicit threat-model paragraph** (contains mistakes,
   not an adversary/escape/exfiltration), scoped the worst case to the working
   tree *plus* whatever those credentials reach, and added a token-exfiltration
   residual risk.

Clarity pass also drove: Quick Start now states it assumes an install; the
